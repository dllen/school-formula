# 打赏功能实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在页脚和知识点详情页底部各加一个「赞赏」入口，点击向上展开含支付宝与微信两张收款码的轻量 Popover。

**Architecture:** 一个自包含的 `DonatePopover` 组件，持有唯一的 `open` 状态；根节点是 `relative inline-block` 定位锚点，Popover 用 `absolute bottom-full left-0` 向上展开。二维码图片放在 `public/donate/`，仅在打开时挂载。两个挂载点传不同 `triggerVariant` 复用同一组件。

**Tech Stack:** React 19 + TypeScript（strict）+ Tailwind CSS v4（项目 OKLCH token）+ Vitest + @testing-library/react（用 `fireEvent`，项目未装 user-event）

**设计文档：** `docs/superpowers/specs/2026-11-10-donate-design.md`

创建 `src/components/DonatePopover.tsx`：

```tsx
import { useId, useRef, useState } from 'react';

interface DonatePopoverProps {
  /** 触发按钮的文字，如「赞赏支持」「赞赏」 */
  triggerLabel: string;
}

const CHANNELS = [
  { src: '/donate/alipay.jpg', alt: '支付宝收款码', label: '支付宝' },
  { src: '/donate/wechat.jpg', alt: '微信收款码', label: '微信支付' },
] as const;

/**
 * 打赏入口：一个轻量 Popover，向上展开支付宝与微信两张收款码。
 *
 * 根节点是定位锚点；面板内容只在打开时挂载，所以二维码图片不会进首屏，
 * 预渲染输出的 HTML 里也只有一个触发按钮。
 */
export function DonatePopover({ triggerLabel }: DonatePopoverProps) {
  const [open, setOpen] = useState(false);
  const rootRef = useRef<HTMLDivElement>(null);
  const triggerRef = useRef<HTMLButtonElement>(null);
  const panelId = useId();

  return (
    <div ref={rootRef} className="relative inline-block">
      <button
        ref={triggerRef}
        type="button"
        onClick={() => setOpen((value) => !value)}
        aria-expanded={open}
        aria-haspopup="dialog"
        aria-controls={open ? panelId : undefined}
        className="text-sm text-ink-2 transition-colors hover:text-accent"
      >
        {triggerLabel}
      </button>

      {open && (
        <div
          id={panelId}
          role="dialog"
          aria-label="赞赏支持"
          tabIndex={-1}
          className="absolute bottom-full left-0 z-30 mb-2 w-max max-w-[calc(100vw-2rem)] rounded-xl border border-rule bg-card p-4 shadow-pop outline-none"
        >
          <p className="mb-2.5 text-xs text-ink-3">如果内容对您有帮助，欢迎扫码支持</p>
          <div className="flex items-start gap-4">
            {CHANNELS.map((channel) => (
              <figure key={channel.src} className="m-0">
                <img
                  src={channel.src}
                  alt={channel.alt}
                  className="h-auto max-h-[260px] w-[148px] rounded-md border border-rule bg-white object-contain sm:w-[168px]"
                />
                <figcaption className="mt-1.5 text-center text-xs text-ink-2">
                  {channel.label}
                </figcaption>
              </figure>
            ))}
          </div>
        </div>
      )}
    </div>
  );
}
```

- [ ] **Step 3: 实现两个关闭监听**

把文件第一行改为：

```tsx
import { useEffect, useId, useRef, useState } from 'react';
```

在 `const panelId = useId();` 之后插入：

```tsx
  // 关闭：点击组件外部
  useEffect(() => {
    if (!open) return;
    const onMouseDown = (event: MouseEvent) => {
      if (!rootRef.current?.contains(event.target as Node)) setOpen(false);
    };
    document.addEventListener('mousedown', onMouseDown);
    return () => document.removeEventListener('mousedown', onMouseDown);
  }, [open]);

  // 关闭：Esc
  useEffect(() => {
    if (!open) return;
    const onKeyDown = (event: KeyboardEvent) => {
      if (event.key === 'Escape') setOpen(false);
    };
    document.addEventListener('keydown', onKeyDown);
    return () => document.removeEventListener('keydown', onKeyDown);
  }, [open]);
```

- [ ] **Step 3: 写视觉核查脚本**

创建 `.donate-check.cjs`：

```js
const http = require('node:http');
const fs = require('node:fs');
const path = require('node:path');
const puppeteer = require('puppeteer-core');

const ROOT = path.resolve('dist');
const CHROME = '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';
const BASE = 'http://localhost:4321';

const server = http.createServer((req, res) => {
  const p = decodeURIComponent(req.url.split('?')[0]);
  let file = path.join(ROOT, p);
  if (!fs.existsSync(file) || fs.statSync(file).isDirectory()) file = path.join(ROOT, 'index.html');
  const ext = path.extname(file);
  res.setHeader('Content-Type', ext === '.html' ? 'text/html' : ext === '.css' ? 'text/css' : ext === '.js' ? 'text/javascript' : 'application/octet-stream');
  res.end(fs.readFileSync(file));
});

(async () => {
  await new Promise((r) => server.listen(4321, r));
  const browser = await puppeteer.launch({ executablePath: CHROME, headless: 'new', args: ['--no-sandbox'] });
  const page = await browser.newPage();
  const errors = [];
  page.on('pageerror', (e) => errors.push(String(e).slice(0, 120)));
  page.on('console', (m) => {
    if (m.type() === 'error' && !m.text().includes('ERR_CONNECTION_REFUSED')) {
      errors.push(m.text().slice(0, 120));
    }
  });
  let bad = 0;

  for (const width of [320, 390, 1440]) {
    await page.setViewport({ width, height: 900 });
    for (const route of ['/', '/knowledge/p-math-001']) {
      await page.goto(BASE + route, { waitUntil: 'networkidle2', timeout: 30000 });

      const result = await page.evaluate(() => {
        const triggers = [...document.querySelectorAll('button[aria-haspopup="dialog"]')];
        const trigger = triggers[triggers.length - 1];
        if (!trigger) return { error: 'no trigger' };
        trigger.click();
        const panel = document.querySelector('[role="dialog"][aria-label="赞赏支持"]');
        if (!panel) return { error: 'no panel' };
        const box = panel.getBoundingClientRect();
        return {
          scrollW: document.documentElement.scrollWidth,
          innerW: window.innerWidth,
          left: Math.round(box.left),
          right: Math.round(box.right),
          width: Math.round(box.width),
          imgs: panel.querySelectorAll('img').length,
        };
      });

      const clipped =
        Boolean(result.error) ||
        result.left < 0 ||
        result.right > result.innerW ||
        result.scrollW > result.innerW;
      if (clipped) bad++;
      console.log(width, route, JSON.stringify(result), clipped ? 'CLIPPED/OVERFLOW' : 'ok');
    }
  }

  const uniqueErrors = [...new Set(errors)];
  console.log(uniqueErrors.length ? 'CONSOLE ERRORS:\n' + uniqueErrors.join('\n') : 'no console errors');
  console.log(bad === 0 && uniqueErrors.length === 0 ? 'ALL OK' : bad + ' PROBLEM(S)');
  server.close();
  await browser.close();
})().catch((e) => {
  console.error('FATAL', e.message);
  process.exit(1);
});
```
