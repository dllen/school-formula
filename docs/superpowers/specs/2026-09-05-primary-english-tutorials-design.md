# 小学英语教程 + 学科切换 UI 设计

**日期**: 2026-09-05
**状态**: 已批准

---

## 1. 背景

当前教程栏目已有数学（6年级×5课）和语文（6年级×5课），但英语教程完全缺失。UI 层面也只有年级选择器，无法切换学科。

## 2. 目标

1. 补齐 1-6 年级英语教程，每年级 5 课
2. UI 增加学科切换 Tab（数学/语文/英语）
3. 保持与现有一致的教/学/练结构和内容深度

## 3. 内容设计

### 3.1 技能递进路线

| 年级 | 核心技能 | 5 课主题 |
|------|---------|---------|
| 1 年级 | 字母 + 语音启蒙 | 字母认读、辅音发音、元音发音、课堂用语、自我介绍 |
| 2 年级 | 拼读 + 基础词汇 | 字母书写、元音组合、辅音组合、颜色数字、日常问候 |
| 3 年级 | 词汇 + 简单句型 | 单词拼读、家庭成员、教室用品、动物描述、简单句型 |
| 4 年级 | 句型 + 话题表达 | 元音字母组合、食物表达、时间表达、周末活动、电子邮件 |
| 5 年级 | 综合技能 | 句型转换、季节描述、生日派对、问路指路、故事阅读 |
| 6 年级 | 语法 + 读写 | 时态入门、比较级最高级、阅读理解、写作基础、总复习 |

## 4. UI 设计

### 4.1 学科切换 Tab

位置：标题「教程」旁边，与年级选择器同行

```
[ 🔢 数学 | 📝 语文 | 🔤 英语 ]    [ 1年级 2年级 3年级 ... ]
```

### 4.2 交互流程

1. 用户点击学科 Tab → 切换学科
2. 年级选择器重置为 1 年级
3. 显示该学科 1 年级的教程列表
4. 用户点击课程卡片 → 进入课程详情（不变）
