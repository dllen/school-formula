# 知识点趣味化设计

> 状态：草案 | 日期：2026-01-09

## 1. 背景与目标

### 1.1 当前问题

拾艺院的知识点浏览模块采用传统的"列表+详情"风格，虽然内容扎实，但对小学生和初中生来说缺乏吸引力。家长反映孩子主动学习的意愿不强，需要让知识本身变得更有吸引力。

### 1.2 设计目标

让知识点浏览变得有趣、有吸引力：
- 用故事卡片替代枯燥列表
- 用生活冷知识激发好奇心
- 用互动问答增加参与感
- 不深入讲解，只点燃兴趣

### 1.3 本期范围

- **学段**：小学数学 + 初中数学（约 12 个知识点）
- **风格**：极简 emoji（大号 emoji + 简洁排版，开发成本低）
- **不涉及**：全局游戏化、答题练习改造、动画效果

## 2. 数据模型扩展

### 2.1 KnowledgePoint 新增字段

```typescript
export interface KnowledgePoint {
  id: string;
  title: string;
  description: string;
  tags?: string[];
  detailedExplanation?: string;
  studyTips?: string[];
  practiceQuestions?: { question: string; answer: string }[];
  
  // === 趣味化新增字段 ===
  /** 主形象 emoji，如 🧮 🔢 📐 */
  funEmoji?: string;
  /** 冷知识 / 趣味事实（一句话） */
  funFact?: string;
  /** 生活中的有趣故事（50-100字） */
  funStory?: string;
  /** 互动小问题 */
  funQuestion?: string;
  /** 互动问题答案 */
  funQuestionAnswer?: string;
}
```

### 2.2 趣味内容来源

由用户为每个知识点提供趣味内容，录入到数据文件中。

## 3. UI 组件设计

### 3.1 知识点卡片改造（KnowledgeList）

**改造前**：纯文字卡片（标题 + 描述）

**改造后**：
```
┌─────────────────────────────────────┐
│  🧮  数的认识                         │
│  整数、小数、分数的认识与比较           │
│                                     │
│  💡 古人最早没有0的概念，是印度人在    │
│     公元5世纪才发明了0！               │
│                                     │
│  🔍 0是偶数还是奇数？ [点击揭晓]       │
└─────────────────────────────────────┘
```

**交互**：
- 默认显示 funFact（冷知识）
- funQuestion 可点击展开答案
- 卡片增加 hover 轻微上浮效果

### 3.2 知识点详情页改造（KnowledgeDetail）

在现有详细解析/学习技巧/实战练习基础上，增加"趣味角"板块：

```
┌─────────────────────────────────────┐
│  数的认识                             │
│  整数、小数、分数的认识与比较           │
├─────────────────────────────────────┤
│  💡 详细解析（折叠）                   │
│  🎓 学习技巧（折叠）                   │
│  ✏️ 实战练习（折叠）                   │
├─────────────────────────────────────┤
│  🌟 趣味角（默认展开）                  │
│                                     │
│  ┌─ 冷知识 ──────────────────────┐  │
│  │ 🧊 0的诞生故事...              │  │
│  └───────────────────────────────┘  │
│                                     │
│  ┌─ 生活中的数学 ─────────────────┐  │
│  │ 💰 为什么1元=10角=100分？      │  │
│  └───────────────────────────────┘  │
│                                     │
│  ┌─ 互动问答 ───────────────────┐   │
│  │ ❓ 0是偶数还是奇数？           │   │
│  │    [点击揭晓答案]              │   │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 3.3 折叠/展开交互

- 详细解析、学习技巧默认折叠（点击展开）
- 趣味角默认展开（因为是核心吸引点）
- 互动问答的答案默认隐藏，点击"揭晓"后显示
- 折叠动画：使用 CSS transition，不引入额外动画库
