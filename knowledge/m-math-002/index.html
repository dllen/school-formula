📖 知识讲解

方程与不等式是刻画相等与不等关系的数学工具。

一元一次方程：只含一个未知数，且未知数的最高次数为1。解方程的五大步骤：去分母、去括号、移项、合并同类项、系数化为 1。每一步都要检验是否等价变形。

二元一次方程组：常用代入消元法和加减消元法，核心思想是"消元"——把二元化为一元。

一元二次方程：ax²+bx+c=0 (a≠0)。三种解法：

  • 因式分解法：若方程左边可分解为两个一次因式之积，则分别令每个因式为 0 求解
  • 配方法：配方成 (x+m)²=n 的形式
  • 公式法：求根公式 x=(-b±√(b²-4ac))/2a，其中 判别式 Δ=b²-4ac 决定根的情况（Δ>0 两不等实根，Δ=0 两相等实根，Δ<0 无实根）

不等式性质：

  • 性质1：两边同加（减）同一个数，不等号方向不变
  • 性质2：两边同乘（除）同一个正数，不等号方向不变
  • 性质3：两边同乘（除）同一个负数，不等号方向改变（最容易出错！）

不等式组口诀：同大取大，同小取小，大小小大中间找，大大小小无处找。

✏️ 例题精讲

基础：解一元一次方程

题目：解方程：3(x-2) = 2x + 1。

解答：去括号：3x - 6 = 2x + 1。移项：3x - 2x = 1 + 6。解得 x = 7。

💡 移项要变号！从等号一边移到另一边，加变减、减变加。

进阶：一元二次方程的解法选择

题目：解方程 x² - 5x + 6 = 0。

解答：因式分解：(x-2)(x-3)=0，所以 x-2=0 或 x-3=0，解得 x₁=2，x₂=3。

💡 优先尝试因式分解法，它最快；分解不了再用公式法。

挑战：不等式与参数

题目：若不等式 (a-1)x > a-1 的解集是 x < 1，求 a 的取值范围。

解答：解集从">"变成了"<"，说明两边同除的 (a-1) 是负数，即 a-1 < 0，所以 a < 1。

💡 不等号方向改变 → 乘（除）的是负数。这是破解含参不等式的关键信号。

🕵️ "方程侦探破案"（约 10 分钟）

  1. 家长写出 3 道不同类型的方程（一元一次、二元一次方程组、一元二次各一道），不要求解，只写方程
  2. 孩子先判断"这是什么方程"并说出判断依据
  3. 选一种解法解出来，口头讲解每一步的依据（"这一步是移项，依据是等式性质1"）
  4. 角色互换：孩子给家长出题，并批改

💡 目的：通过"讲解步骤依据"训练解法的逻辑性，避免"只知其然不知其所以然"。

📝 课后练习

第 1 题：解方程组：{ 2x + y = 7; x - y = -1 }

✅ 答案：x = 2, y = 3

解析：两式相加得 3x = 6，x = 2；代入 x - y = -1 得 2 - y = -1，y = 3。

第 2 题：解不等式组：{ 2x - 1 ≤ 5; 3x + 2 > 8 }，并在数轴上表示解集。

✅ 答案：2 < x ≤ 3

解析：由 2x-1≤5 得 x≤3；由 3x+2>8 得 x>2。取交集得 2 < x ≤ 3。

第 3 题：已知关于 x 的方程 x² + kx + 9 = 0 有两个相等的实数根，求 k 的值。

✅ 答案：k = 6 或 k = -6

解析：Δ = k² - 36 = 0，k² = 36，k = ±6。

第 4 题：某班学生去划船，若每船坐4人则多3人；若每船坐5人则少2个位置。问共有多少名学生？

✅ 答案：23名学生

解析：设船 x 条，4x+3 = 5x-2，解得 x=5，学生数 = 4×5+3 = 23。

🌟 趣味角

🧊 冷知识

方程的英文 equation 来自拉丁语 aequatio，意思是"使相等"。解方程就是找出让等式成立的未知数！

📖 生活中的数学

想象你是一个侦探，方程就是一个谜题："一个数的3倍加上5等于20，这个数是多少？"解方程的过程就是破案的过程，x就是你要找的"嫌疑人"！

❓ 互动问答

为什么叫"方程"不叫"等式"？

▶点击揭晓答案

"方"是并列的意思。古代把未知数和已知数并列成方阵一样的排列，所以叫方程。
