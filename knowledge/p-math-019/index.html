📖 知识讲解

判断一个数能不能被另一个数整除，不需要真的做除法！记住这些"特征"，一眼就能看出来。

2 的倍数特征：个位是 0、2、4、6、8（偶数） 5 的倍数特征：个位是 0 或 5 3 的倍数特征：各位数字之和是 3 的倍数 9 的倍数特征：各位数字之和是 9 的倍数

记忆口诀：

  • 2 看个位是偶数
  • 5 看个位 0 或 5
  • 3 和 9 看"数字和"

为什么 3 的倍数要看数字和？

  • 比如 123：123 = 100 + 20 + 3 = 99 + 1 + 9×2 + 3
  • 99 和 9×2 都是 3 的倍数，所以只要 1 + 2 + 3 = 6 是 3 的倍数就行

✏️ 例题精讲

基础：判断 2、3、5 的倍数

题目：判断 252 是不是 2、3、5 的倍数？

解答：个位是 2（偶数）→ 是 2 的倍数。数字和 = 2+5+2 = 9，是 3 的倍数 → 是 3 的倍数。个位不是 0 或 5 → 不是 5 的倍数。

💡 2 看个位偶数，3 看数字和，5 看个位 0 或 5。

进阶：组数

题目：用 0、3、5 三张卡片，组成一个是 2、3、5 的公倍数的三位数，最小是多少？

解答：2、5 的倍数 → 个位是 0。3 的倍数 → 数字和是 3 的倍数。3+5+0 = 8（不是 3 的倍数），5+3+0 = 8（不是），3+0+0 = 3（是）。最小是 300。

💡 先满足 2 和 5（个位是 0），再满足 3（数字和是 3 的倍数）。

挑战：填数

题目：在□里填一个数字，使 45□ 同时是 2 和 3 的倍数。有几种填法？

解答：是 2 的倍数 → 个位是 0、2、4、6、8。是 3 的倍数 → 4+5+□ = 9+□ 是 3 的倍数。□可以是 0、3、6、9。取交集：□ = 0 或 6。共 2 种填法。

💡 分别列出满足条件的数，再取交集。

📝 课后练习

第 1 题：判断 135 是不是 2、3、5 的倍数？

✅ 答案：不是 2 的倍数，是 3 的倍数，是 5 的倍数

解析：个位 5 不是偶数 → 不是 2 的倍数；1+3+5=9 是 3 的倍数 → 是 3 的倍数；个位是 5 → 是 5 的倍数。

第 2 题：一个三位数 24□，既是 2 的倍数又是 3 的倍数，□可以填几？

✅ 答案：0 或 6

解析：是 2 的倍数 → □是 0、2、4、6、8；是 3 的倍数 → 2+4+□=6+□是 3 的倍数 → □是 0、3、6、9。取交集：0 或 6。

第 3 题：用 1、2、3、4 组成一个既是 2 的倍数又是 3 的倍数的最大四位数是多少？

✅ 答案：不存在（1+2+3+4=10 不是 3 的倍数）

解析：1+2+3+4=10，不是 3 的倍数，所以无论怎么排列都不是 3 的倍数。

第 4 题：5 的倍数中，最小的三位偶数是多少？

✅ 答案：100

解析：5 的倍数且是偶数 → 个位是 0，最小三位数是 100。
