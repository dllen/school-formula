金属

化学

金属材料，金属的化学性质，金属资源的利用和保护。

系统教程

本课目标

  • 了解金属材料的分类（纯金属和合金），知道合金的性质特点
  • 掌握金属的三条化学性质：与氧气反应、与酸反应、与盐溶液反应
  • 熟记金属活动性顺序，能判断金属与酸、金属与盐溶液能否发生反应
  • 理解铁的冶炼原理（3CO + Fe₂O₃ 高温→ 2Fe + 3CO₂）和铁生锈的条件
  • 了解金属防锈方法和金属资源的保护

知识讲解

金属和金属材料在生产生活中应用广泛。从易拉罐到自行车，从电线到炊具，金属无处不在。

金属材料：

  • 包括纯金属和合金
  • 合金是混合物，硬度比组分金属大、熔点比组分金属低
  • 常见合金：生铁和钢（含碳量不同，生铁含碳2%~4.3%，钢含碳0.03%~2%）、黄铜（铜锌合金）、铝合金

金属的化学性质：

  1. 与氧气反应：
    • 4Al + 3O₂ = 2Al₂O₃（铝表面形成致密氧化膜，保护内部，所以铝耐腐蚀）
    • 3Fe + 2O₂ 点燃→ Fe₃O₄（铁在纯氧中剧烈燃烧）
  2. 与酸反应（活泼金属）：Zn + H₂SO₄ = ZnSO₄ + H₂↑（置换反应）
  3. 与盐溶液反应：Fe + CuSO₄ = FeSO₄ + Cu（湿法炼铜）

金属活动性顺序：K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au

  • 排在氢前的金属能与稀盐酸/稀硫酸反应放出氢气
  • 排在前面的金属能把排在后面的金属从其盐溶液中置换出来

铁的冶炼：高炉炼铁原理：3CO + Fe₂O₃ 高温→ 2Fe + 3CO₂

铁生锈的条件：与氧气和水同时接触。 防锈方法：刷漆、涂油、镀其他金属、制成不锈钢、保持铁制品干燥洁净。

例题精讲

基础：判断反应能否发生

题目：判断下列物质能否发生反应，能反应的写出化学方程式：①铜与稀硫酸 ②锌与硫酸亚铁溶液

解答：①不能反应。铜排在氢后面，不能与稀硫酸反应。②能反应。锌排在铁前面，能把铁置换出来：Zn + FeSO₄ = ZnSO₄ + Fe

判断依据：金属活动性顺序。氢前的金属能与酸反应；排在前面的金属能把后面的金属从其盐溶液中置换出来。

进阶：金属活动性实验设计

题目：如何用实验验证Fe、Cu、Ag三种金属的活动性顺序？请写出一种方案（可选药品：Fe、Cu、Ag、FeSO₄溶液、CuSO₄溶液、AgNO₃溶液）。

解答：方案（两盐夹一法）：将Cu丝分别插入FeSO₄溶液和AgNO₃溶液中。现象：Cu与FeSO₄不反应（说明Fe>Cu），Cu与AgNO₃反应析出银白色固体（说明Cu>Ag）。结论：Fe>Cu>Ag。

验证三种金属活动性可用"两金夹一盐"或"两盐夹一金"法，只需做两个实验。

挑战：综合计算

题目：将10g铁钉放入一定量的硫酸铜溶液中，反应一段时间后取出铁钉，称量发现质量变为10.8g。求析出铜的质量。

解答：Fe + CuSO₄ = FeSO₄ + Cu，每56份质量的铁置换出64份质量的铜，固体增重8份。设析出铜的质量为x。64/x = 8/(10.8-10)g = 8/0.8g，x = 6.4g。答：析出铜的质量为6.4g。

利用"差量法"计算：反应前后固体质量差 = 析出金属质量 - 溶解金属质量。

亲子互动

⚙️ "金属活动性侦探"实验（约 10 分钟）

准备：铁钉（或铁丝）、铜丝、稀盐酸（或稀硫酸）、硫酸铜溶液、试管若干。

  1. 将铁钉放入稀盐酸中，观察现象（产生气泡，溶液由无色变为浅绿色）
  2. 将铜丝放入稀盐酸中，观察现象（无气泡，不反应）
  3. 将铁钉放入硫酸铜溶液中，观察现象（铁钉表面析出红色固体，溶液由蓝色变为浅绿色）
  4. 将铜丝放入硫酸铜溶液中，观察现象（无变化）
  5. 根据现象排出Fe、Cu、H的活动性顺序

💡 目的：通过亲手实验验证金属活动性顺序，理解"结构决定性质"在金属化学中的体现。

课后练习

第 1 题：下列金属中，能与稀盐酸反应放出氢气的是（ ）A.Cu B.Ag C.Zn D.Hg

答案：C

解析：只有排在氢前面的金属才能与稀盐酸反应，Zn在氢前，Cu、Ag、Hg都在氢后。

第 2 题：铝制品为什么比铁制品更耐腐蚀？写出铝与氧气反应的化学方程式。

答案：铝在空气中与氧气反应，表面生成一层致密的氧化铝（Al₂O₃）薄膜，阻止铝进一步氧化。4Al + 3O₂ = 2Al₂O₃。

解析：铝的氧化膜致密且牢固，起保护作用；铁锈疏松多孔，不能保护内部铁。

第 3 题：把锌片放入硝酸银溶液中，观察到的现象是什么？写出反应的化学方程式。

答案：锌片表面有银白色固体析出。Zn + 2AgNO₃ = Zn(NO₃)₂ + 2Ag。

解析：锌比银活泼，能把银从硝酸银溶液中置换出来，在锌片表面析出银白色的银。

第 4 题：铁生锈的条件是什么？菜刀防锈的常用方法有哪些？（写出两种）

答案：与氧气和水同时接触。防锈方法：用后擦干、涂食用油、保持干燥等。

解析：破坏铁生锈的条件（隔绝氧气或水）即可防锈。

实战练习

Q1: 把铁钉放入硫酸铜溶液中，能观察到什么现象？写出化学方程式。

参考答案铁钉表面有红色物质析出，溶液由蓝色逐渐变为浅绿色。Fe + CuSO₄ = FeSO₄ + Cu

Q2: 铝比铁活泼，但为什么铝制品比铁制品更耐腐蚀？

参考答案铝在空气中与氧气反应，表面生成一层致密的氧化铝薄膜，阻止铝进一步氧化；铁锈疏松多孔，不能保护内部的铁。

Q3: 铁生锈需要什么条件？列举两种防锈方法。

参考答案与氧气和水同时接触。刷漆、涂油（或镀其他金属、制成合金等）。
