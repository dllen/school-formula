化学计量

化学

物质的量，摩尔质量，气体摩尔体积，物质的量浓度。

系统教程

本课目标

  • 能准确理解物质的量（n）、摩尔质量（M）、气体摩尔体积（Vm）、物质的量浓度（c）的概念与单位
  • 会运用换算关系式 n = m/M = V/Vm = cV 进行各物理量之间的相互计算
  • 掌握以"物质的量"为中心的计量关系网络，能进行多步综合计算
  • 理解气体摩尔体积成立的前提条件（标准状况、气态物质）

知识讲解

以"物质的量（n）"为核心，我们可以串联起宏观可测的物理量（质量、体积、溶液浓度）与微观粒子数之间的定量关系。

**物质的量（n）**是国际单位制中 7 个基本物理量之一，单位是摩尔（mol）。1 mol 任何粒子集体中所含的粒子数约为 6.02×10²³（阿伏伽德罗常数 NA）。换算：N = n·NA。

**摩尔质量（M）**是单位物质的量的物质所具有的质量，单位 g/mol，数值上等于该物质的相对分子（原子）质量。如 M(H₂O) = 18 g/mol。

气体摩尔体积（Vm）：在标准状况（0℃，101 kPa）下，1 mol 任何气体的体积都约为 22.4 L。使用时注意两个前提——"标准状况"与"气态"。

换算关系网络：n = m/M = V/Vm = cV（溶液）。这是整个高中化学定量计算的枢纽，务必烂熟于心。

例题精讲

基础：已知物质的量求质量

题目：3 mol CO₂ 的质量是多少克？

解答：M(CO₂) = 44 g/mol，m = n·M = 3 mol × 44 g/mol = 132 g。

摩尔质量数值等于相对分子质量，注意单位 g/mol。

进阶：标准状况下气体体积与粒子数的换算

题目：标准状况下，11.2 L O₂ 所含的分子数是多少？

解答：n = V/Vm = 11.2 L / 22.4 L/mol = 0.5 mol；N = n·NA = 0.5 × 6.02×10²³ = 3.01×10²³。

先由体积算出物质的量，再由物质的量换算粒子数，分步进行不易出错。

挑战：溶液的物质的量浓度

题目：将 4 g NaOH 溶于水配成 500 mL 溶液，该溶液的物质的量浓度是多少？

解答：n(NaOH) = 4 g / 40 g/mol = 0.1 mol；c = n/V = 0.1 mol / 0.5 L = 0.2 mol/L。

体积单位必须换算为升（L），这是计算浓度时最常见的错误。

亲子互动

🧮 "摩尔桥梁"定量推导（约 8 分钟）

  1. 在纸上画一个中心词"n（物质的量）"，向外引出四条线，分别标注 m、V（气）、c、N
  2. 每条线上写出对应的转化公式（n=m/M、n=V/Vm、n=cV、n=N/NA）
  3. 完成推导：5.6 g 铁粉与足量稀硫酸反应，标准状况下生成 H₂ 的体积是多少？请用 n 作桥梁分步列式
  4. 核对：n(Fe) = 5.6/56 = 0.1 mol → n(H₂) = 0.1 mol → V(H₂) = 0.1 × 22.4 = 2.24 L

💡 目的：把"以物质的量为中心"的计量关系从记忆转化为可视化的思维地图，培养定量推导的规范习惯。

课后练习

第 1 题：标准状况下，33.6 L CO₂ 的物质的量是多少？质量是多少？

答案：n = 33.6/22.4 = 1.5 mol；m = 1.5 × 44 = 66 g

解析：先由 V/Vm 算出 n，再由 n·M 算出 m。

第 2 题：5.6 g Fe 的物质的量是多少？含多少个铁原子？

答案：n = 5.6/56 = 0.1 mol；N = 0.1 × 6.02×10²³ = 6.02×10²²

解析：M(Fe) = 56 g/mol，再用 N = n·NA 换算粒子数。

第 3 题：配制 250 mL 0.2 mol/L 的 NaCl 溶液，需要 NaCl 的质量是多少？

答案：n = cV = 0.2 × 0.25 = 0.05 mol；m = 0.05 × 58.5 = 2.925 g

解析：注意体积单位换算：250 mL = 0.25 L。

第 4 题：下列说法正确的是（ ）。A. 1 mol H₂O 的质量是 18 g/mol B. 标准状况下，1 mol 任何物质的体积都约为 22.4 L C. 1 mol CO₂ 含有 1 mol C 和 2 mol O D. 0.5 mol O₂ 的质量是 16 g/mol

答案：C

解析：A 单位错误，应为 18 g；B 仅限气体；D 单位错误，应为 16 g。1 mol CO₂ 含 1 mol C 和 2 mol O 原子，C 正确。
