函数

数学

平面直角坐标系、一次函数、反比例函数、二次函数。

系统教程

本课目标

  • 理解函数的概念——每一个自变量对应唯一的因变量
  • 会画一次函数、反比例函数、二次函数的图像，并能从图像读取性质
  • 能把二次函数的一般式化为顶点式，快速得到顶点坐标和对称轴
  • 能根据图像判断 k、a 的正负对图像位置和变化趋势的影响

知识讲解

函数描述的是两个变量之间的"对应关系"——给定一个 x，有唯一的 y 与之对应。

一次函数：y = kx + b（k ≠ 0）。

  • 图像是一条直线。k 叫斜率：k>0 时 y 随 x 增大而增大（上升）；k<0 时 y 随 x 增大而减小（下降）。| k | 越大，直线越陡。b 叫截距：直线与 y 轴交于点 (0, b)。
  • 正比例函数：y = kx（b=0），图像过原点。

反比例函数：y = k/x（k ≠ 0）。

  • 图像是双曲线。k>0 时双曲线在一、三象限；k<0 时在二、四象限。
  • 在每个象限内，k>0 时 y 随 x 增大而减小；k<0 时 y 随 x 增大而增大。注意：必须强调"在每个象限内"这个前提。

二次函数：y = ax² + bx + c（a ≠ 0）。

  • 图像是抛物线。a>0 开口向上，有最低点（最小值）；a<0 开口向下，有最高点（最大值）。
  • 顶点式：y = a(x-h)² + k，顶点为 (h, k)，对称轴为 x = h。把一般式配方就能得到顶点式。
  • 与 x 轴交点个数由判别式 Δ=b²-4ac 决定。

例题精讲

基础：从表达式判断图像

题目：不画图，判断 y = -3x + 2 和 y = -3x 的图像各有什么特点，它们有什么关系？

解答：两者 k 都为 -3（<0），所以 y 随 x 增大而减小。b 不同：y=-3x+2 交 y 轴于 (0,2)，y=-3x 过原点。因为 k 相同，所以两直线平行。

k 决定倾斜方向和陡度，b 决定上下位置。k 相同 → 平行。

进阶：二次函数的一般式化为顶点式

题目：把 y = x² - 4x + 3 化为顶点式，并求顶点坐标和最小值。

解答：配方：y = (x² - 4x + 4) - 4 + 3 = (x-2)² - 1。顶点为 (2, -1)。因为 a=1>0 开口向上，所以最小值为 -1。

配方口诀：取一次项系数一半的平方，加上再减去。

挑战：函数图像综合判断

题目：已知二次函数 y = ax² + bx + c 的图像开口向下，顶点在第一象限，与 y 轴交于正半轴。判断 a、b、c 以及 b²-4ac 的符号。

解答：开口向下 → a<0。顶点 (-b/2a, ...) 在第一象限 → -b/2a > 0，因为 a<0 所以 b<0。与 y 轴交于正半轴 → c>0。顶点在第一象限说明有交点 → Δ=b²-4ac>0。

把"图像语言"翻译成"符号语言"：开口方向↔a，对称轴位置↔b，交点↔Δ。

亲子互动

📈 "函数图像速写赛"（约 10 分钟）

  1. 准备坐标纸（或方格纸）和笔
  2. 家长给出一个函数表达式（如 y=2x-1、y=-6/x、y=-(x+1)²+3），孩子在 2 分钟内画出草图并标注关键点（交点、顶点、渐近线等）
  3. 画完后，家长根据图像反问："这条直线是上升还是下降？""这条抛物线有最大值还是最小值？"
  4. 互换角色，让孩子出题考家长

💡 目的：训练"数形结合"思维——看到表达式想图像，看到图像想性质。

课后练习

第 1 题：一次函数 y = -2x + 4 与 x 轴、y 轴的交点坐标分别是多少？图像经过哪几个象限？

答案：与 x 轴交于 (2,0)，与 y 轴交于 (0,4)；经过一、二、四象限

解析：令 y=0 得 x=2；令 x=0 得 y=4。k<0 下降，b>0 交 y 轴正半轴，故过一、二、四象限。

第 2 题：反比例函数 y = -8/x，当 x₁=-2、x₂=4 时，比较对应的 y₁ 和 y₂ 的大小。

答案：y₁ > y₂

解析：y₁ = -8/(-2) = 4，y₂ = -8/4 = -2，所以 4 > -2，即 y₁ > y₂。

第 3 题：把 y = -x² + 6x - 5 化为顶点式，并求最大值和对称轴。

答案：y = -(x-3)² + 4；最大值为 4；对称轴 x = 3

解析：配方：y = -(x²-6x) - 5 = -(x-3)² + 9 - 5 = -(x-3)² + 4。a<0 开口向下，最大值即顶点纵坐标 4。

第 4 题：已知抛物线 y = x² + bx + 9 的顶点在 x 轴上，求 b 的值。

答案：b = 6 或 b = -6

解析：顶点在 x 轴上 → Δ = b² - 36 = 0 → b = ±6。

趣味角

冷知识

函数的概念是数学家莱布尼茨在1673年提出的，现在它是整个现代数学的基石！

生活中的数学

函数就像一个"魔法盒子"：你放进去一个数（输入），它就会变出另一个数（输出）。比如超市苹果10元/斤，放进去2斤，变出20元。放进去5斤，变出50元。这就是函数！

互动问答

圆的面积公式S=πr²是函数吗？

点击揭晓答案

是！半径r是自变量，面积S是因变量。每个r对应唯一的S，所以S=πr²是一个函数。
