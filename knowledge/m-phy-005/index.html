物理

力学与运动

参照物，速度，质量与密度，力，二力平衡，摩擦力，压强，浮力，杠杆，滑轮，功与功率，机械效率。

系统教程

本课目标

  • 理解速度公式 v=s/t 及单位换算（1 m/s = 3.6 km/h）
  • 掌握密度的概念及公式 ρ=m/V，能进行简单的密度计算
  • 理解二力平衡条件，能判断物体是否处于平衡状态
  • 掌握阿基米德原理 F浮=ρ液gV排，能计算浮力并判断物体的浮沉

知识讲解

力学是初中物理的"半壁江山"。从日常生活到工程技术，力学的应用无处不在。本节涵盖运动、质量密度、力、压强、浮力、杠杆和功的核心公式和概念。

运动与速度：

  • 运动和静止是相对的，取决于参照物。
  • 速度公式：v = s/t，变形 s = vt，t = s/v。
  • 单位换算：1 m/s = 3.6 km/h。

质量与密度：

  • 质量（m）：物体所含物质的多少，不随位置、状态、形状改变。
  • 密度（ρ）：ρ = m/V，是物质的特性（同种物质密度一般相同）。
  • 应用：鉴别物质、计算不规则物体体积、判断空心实心。

力与运动：

  • 力的作用效果：改变物体形状、改变物体运动状态。
  • 重力：G = mg（g 取 9.8 N/kg，粗略计算取 10 N/kg）。
  • 二力平衡条件：同体、等大、反向、共线。平衡力与相互作用力的区别：平衡力作用在同一物体上。

压强：

  • 固体压强：p = F/S（压力/受力面积）。增大压强：增大压力或减小面积。
  • 液体压强：p = ρgh，只与液体密度和深度有关。

浮力：

  • 阿基米德原理：F浮 = ρ液gV排。浮力只与液体密度和排开液体的体积有关，与浸没深度无关。
  • 浮沉条件：F浮 > G 上浮；F浮 = G 悬浮/漂浮；F浮 < G 下沉。

简单机械：

  • 杠杆平衡：F₁L₁ = F₂L₂。
  • 功：W = Fs；功率：P = W/t = Fv；机械效率：η = W有用/W总 × 100% < 100%。

例题精讲

基础：密度公式的计算

题目：一个铁块的质量是 158 g，体积是 20 cm³，铁的密度是多少？若将其截去一半，剩余部分的密度是多少？

解答：ρ = m/V = 158 g / 20 cm³ = 7.9 g/cm³。截去一半后密度不变，仍是 7.9 g/cm³（密度是物质的特性，与质量体积无关）。

密度是物质的特性，同种物质密度一般不变。不能说"密度与质量成正比"——这是易错点！

进阶：压强的分析与计算

题目：一块砖重 20 N，长 20 cm、宽 10 cm、高 5 cm。平放和竖放在水平地面上，对地面的压强各是多少？

解答：平放：S₁ = 20×10 = 200 cm² = 0.02 m²，p₁ = F/S₁ = 20/0.02 = 1000 Pa。竖放（以宽×高为底）：S₂ = 10×5 = 50 cm² = 0.005 m²，p₂ = 20/0.005 = 4000 Pa。

压强公式中的 S 是受力面积（接触面积），不是表面积。单位必须用 m²。

挑战：浮力与密度的综合

题目：一个物体的体积为 500 cm³，重 4 N，放入足够深的水中（ρ水=1 g/cm³，g=10 N/kg），最终受到的浮力是多少？

解答：先算物体密度判断浮沉：m = G/g = 4/10 = 0.4 kg = 400 g，ρ物 = m/V = 400/500 = 0.8 g/cm³ < ρ水，所以物体漂浮。漂浮时 F浮 = G = 4 N。（注意：不能直接用 F浮=ρ水gV排=1×10×0.0005=5 N，因为物体没有完全浸没）

计算浮力的正确步骤：①判断浮沉状态 → ②漂浮/悬浮用 F浮=G；沉底用 F浮=ρ液gV排。

课后练习

第 1 题：一个物体做匀速直线运动，通过 100 m 的路程用了 20 s，它的速度是多少 m/s？合多少 km/h？

答案：v = s/t = 100/20 = 5 m/s = 5 × 3.6 = 18 km/h

解析：速度公式 v=s/t，单位换算 1 m/s = 3.6 km/h。

第 2 题：一个铁球体积为 100 cm³，质量为 600 g，铁的密度为 7.9 g/cm³。这个铁球是空心的还是实心的？如果是空心的，空心体积多大？

答案：空心；空心体积约 24.1 cm³

解析：实心铁球体积 V实 = m/ρ = 600/7.9 ≈ 75.9 cm³ < 100 cm³，所以是空心的。空心体积 = 100 - 75.9 = 24.1 cm³。

第 3 题：一个物体在水平地面上做匀速直线运动，受到的摩擦力为 20 N，则水平拉力是多少？为什么？

答案：20 N。匀速直线运动 → 受力平衡 → 拉力 = 摩擦力 = 20 N。

解析：匀速直线运动是平衡状态，水平方向拉力与摩擦力是一对平衡力，大小相等。

第 4 题：一个体积为 300 cm³、重 2.4 N 的物体放入水中，最终受到的浮力是多少？（g=10 N/kg）

答案：2.4 N

解析：ρ物 = m/V = (2.4/10)/0.0003 = 0.24/0.0003 = 800 kg/m³ < ρ水，漂浮，F浮 = G = 2.4 N。

实战练习

  1. Q1一个物体的质量是5kg，它受到的重力是多少？（g取10N/kg）

    参考答案G = mg = 5×10 = 50N

  2. Q2一块砖平放和竖放在水平地面上，对地面的压力和压强如何变化？

    参考答案压力不变（都等于重力）；竖放时受力面积小，压强变大。

  3. Q3把一个物体浸没在水中，它受到的浮力与什么有关？

    参考答案与液体的密度和排开液体的体积有关，与浸没的深度无关。
