用 This is a 介绍动物

英语

用 This is a 加上动物名词介绍一只动物。

日常表达grade-3cnm:cne_p018ces-2022:1.FU.02

📚 系统教程

🎯 本课目标

  • 掌握 'This is a...' 介绍动物的句型
  • 理解不定冠词 'a' 在句中的作用
  • 能根据动物图片或中文，正确输出介绍句

📖 知识讲解

当我们要向别人介绍一只动物时，可以使用这个句型： This is a + 动物.

  • This is = 这是
  • a = 一只

例如：看到一只猫，可以说 "This is a cat." (这是一只猫。)

✏️ 例题精讲

介绍小狗

题目：看到一只小狗，如何用英文说 '这是一只狗'？

解答：This is a dog.

💡 记得在 dog 前面加上 a，表示 '一只'。

介绍小鸟

题目：看到一只小鸟，如何用英文说 '这是一只鸟'？

解答：This is a bird.

💡 结构：This is a + 动物名称。

🧩 亲子互动

找一张动物照片，指着它大声说出：'This is a [动物名称]'。

📝 课后练习

第 1 题：介绍一只猫，应该说： A. This is a cat. B. This is my cat.

✅ 答案：A

解析：介绍某种动物通常用 This is a... (这是一只...)

第 2 题：这句话的意思是 '这是一只鸭子'：( ) is a duck. A. That B. This

✅ 答案：B

解析： '这' 对应 This。

第 3 题：将 '这是一只狗' 翻译成英文：( )

✅ 答案：This is a dog.

解析：This is a + dog (狗)。
