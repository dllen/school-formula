📖 知识讲解

什么是小数？

当我们把一个整体平均分成 10 份，其中的 1 份我们可以写成 $\frac{1}{10}$，也可以写成 0.1（读作：零点一）。

生活中的例子：

  • 钱： 1 角 = 0.1 元
  • 长度： 1 分米 = 0.1 米

小数的组成： 小数由整数部分（小数点左边）和小数部分（小数点右边）组成。例如 0.7 中，0 是整数部分，7 是小数部分。

✏️ 例题精讲

基础转换

题目：请把 3 角写成元。

解答：因为 1 角 = 0.1 元，所以 3 角 = 0.3 元。

💡 记得 10 个 1 角才等于 1 元，所以 1 角就是 0.1 元。

长度转换

题目：一根绳子长 7 分米，请问它长多少米？

解答：因为 1 分米 = 0.1 米，所以 7 分米 = 0.7 米。

💡 分米和米的关系就像角和元的关系一样。

大小比较

题目：比较 0.4 和 0.6 的大小。

解答：0.4 表示十分之四，0.6 表示十分之六。因为 $4 < 6$，所以 $0.4 < 0.6$。

💡 比较一位小数大小时，直接比较小数点后的数字即可。

试着在家里找找看，有哪些东西的长度可以用 0.几 米来表示？（比如一个笔记本大约 0.2 米长）

📝 课后练习

第 1 题：5 角 = ( ) 元

✅ 答案：0.5

解析：1 角 = 0.1 元，5 个 0.1 就是 0.5。

第 2 题：9 分米 = ( ) 米

✅ 答案：0.9

解析：1 分米 = 0.1 米，9 分米 = 0.9 米。

第 3 题：比较 0.8 和 0.3 的大小，用 >、< 或 = 填空：0.8 ( ) 0.3

✅ 答案：>

解析：8 分之十比 3 分之十大。

第 4 题：把 $\frac{2}{10}$ 写成小数形式。

✅ 答案：0.2

解析：十分之二写成小数就是 0.2。

✏️ 实战练习

参考答案0.3
