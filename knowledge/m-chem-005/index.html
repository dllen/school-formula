碳和碳的氧化物

化学

金刚石、石墨，二氧化碳，一氧化碳。

系统教程

本课目标

  • 了解金刚石、石墨和C₆₀等碳单质，理解它们物理性质差异大的原因（碳原子排列方式不同）
  • 掌握碳的化学性质：常温稳定性、可燃性（充分/不充分燃烧）、还原性
  • 掌握CO₂的物理性质和化学性质（不燃烧不支持燃烧、与水反应、与石灰水反应）
  • 掌握CO₂的实验室制法原理（CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑）和检验方法
  • 了解CO的可燃性和还原性，知道CO的毒性原理（与血红蛋白结合）

知识讲解

碳和碳的氧化物是初中化学的重点内容。从最硬的金墨到软滑的石墨，再到重要的气体CO₂和有毒的CO，碳元素展现出丰富的化学世界。

碳的单质：

  • 金刚石：自然界最硬的物质，无色透明，可做钻头、裁玻璃、加工成钻石
  • 石墨：灰黑色、质软、有滑腻感、导电性好，可做电极、铅笔芯、润滑剂
  • C₆₀：由60个碳原子构成的分子，形似足球

它们物理性质差异很大，但化学性质相似。原因是：碳原子的排列方式不同（结构决定性质）。

碳的化学性质：

  • 常温下稳定（用墨写的字画经久不褪色）
  • 可燃性：充分燃烧 C + O₂ 点燃→ CO₂；不充分燃烧 2C + O₂ 点燃→ 2CO
  • 还原性：C + 2CuO 高温→ 2Cu + CO₂↑（黑色粉末变红，石灰水变浑浊）

二氧化碳（CO₂）：

  • 物理性质：无色无味，密度比空气大，能溶于水，固态叫"干冰"（升华吸热，用于人工降雨、制冷剂）
  • 化学性质：
    • 不燃烧也不支持燃烧（用于灭火）
    • 与水反应：CO₂ + H₂O = H₂CO₃（碳酸能使紫色石蕊变红）
    • 使澄清石灰水变浑浊：CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O（检验CO₂的方法）
  • 实验室制取：大理石/石灰石与稀盐酸：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑，用向上排空气法收集

一氧化碳（CO）：

  • 无色无味，难溶于水，有毒（与血红蛋白结合能力比氧气强200多倍，使人缺氧中毒）
  • 可燃性：2CO + O₂ 点燃→ 点燃前必须验纯！
  • 还原性：CO + CuO △→ Cu + CO₂（用于冶炼金属）

例题精讲

基础：检验CO₂并解释现象

题目：将气体通入澄清石灰水，石灰水变浑浊。写出反应的化学方程式，并说明该反应的一种用途。

解答：CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O。用途：检验二氧化碳气体（或用石灰浆粉刷墙壁，CO₂使石灰浆硬化）。

使澄清石灰水变浑浊是CO₂的特征反应，常用来检验CO₂。

进阶：CO与CO₂性质对比

题目：CO和CO₂的组成元素相同，但性质差异很大。请从分子构成角度解释原因，并各写出一条化学性质不同的实例。

解答：CO和CO₂的分子构成不同：一个CO分子由1个碳原子和1个氧原子构成，一个CO₂分子由1个碳原子和2个氧原子构成。性质差异实例：CO₂不燃烧也不支持燃烧，可用于燃烧；CO有可燃性，能做燃料（或CO有毒而CO₂无毒）。

结构决定性质——分子构成不同，性质就不同。

挑战：碳的还原性实验

题目：碳与氧化铜反应的实验中，为什么要将导管通入澄清石灰水？实验结束时，为什么要先把导管从石灰水中取出，再停止加热？

解答：通入石灰水是为了检验生成的CO₂，并吸收尾气防止污染。实验结束时先取出导管再停止加热，是为了防止石灰水倒流进热试管导致试管炸裂。

实验操作中"先撤管后熄灯"是为了防倒流炸裂，这是常见考点。

亲子互动

🧪 "CO₂的制取与检验"迷你实验（约 10 分钟）

准备：大理石碎片（或鸡蛋壳）、稀盐酸（可用醋替代）、试管、导管、澄清石灰水。

  1. 将大理石放入试管，加入适量稀盐酸，观察现象（有大量气泡产生）
  2. 将导管通入澄清石灰水，观察石灰水变浑浊
  3. 收集一瓶CO₂（向上排空气法），将燃着的木条放在瓶口验满（木条熄灭则满）
  4. 将一瓶CO₂慢慢倒入放有高低两支燃着蜡烛的烧杯中，观察哪支蜡烛先熄灭

💡 目的：亲手制取并检验CO₂，直观感受"CO₂密度比空气大、不支持燃烧"的性质。

课后练习

第 1 题：金刚石和石墨的物理性质差异很大，但化学性质相似。原因是（ ）A.都是由碳原子构成 B.碳原子的排列方式不同 C.都是无色透明 D.都能导电

答案：B

解析：物理性质取决于碳原子的排列方式，化学性质取决于组成元素（都是碳元素）。

第 2 题：写出实验室制取二氧化碳的化学方程式。为什么不用稀硫酸？

答案：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑。因为稀硫酸与碳酸钙反应生成的硫酸钙微溶于水，会覆盖在大理石表面阻止反应继续进行。

解析：反应物浓度和生成物的溶解性会影响反应能否持续进行。

第 3 题：CO还原CuO的实验：①实验开始时，为什么要先通入CO再加热？②尾气为什么要点燃处理？

答案：①先通CO排尽装置内空气，防止CO与空气混合加热发生爆炸。②CO有毒，直接排放会污染空气，点燃使其转化为无毒的CO₂。

解析：CO具有可燃性和毒性，实验安全和尾气处理都很重要。

第 4 题：如何鉴别CO和CO₂两种气体？写出两种不同方法。

答案：方法1：分别通入澄清石灰水，变浑浊的是CO₂，不变的是CO。方法2：分别点燃，能燃烧的是CO，使燃着木条熄灭的是CO₂。

解析：利用两种气体化学性质的不同进行鉴别。

实战练习

Q1: 金刚石和石墨物理性质差异很大的原因是什么？

参考答案碳原子的排列方式不同

Q2: 如何检验一瓶气体是二氧化碳？写出反应的化学方程式。

参考答案通入澄清石灰水，石灰水变浑浊。CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O

Q3: 冬天用煤炉取暖为什么要保持室内通风？

参考答案煤不充分燃烧会产生一氧化碳，CO有毒，与血红蛋白结合使人缺氧中毒。
