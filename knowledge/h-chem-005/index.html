化学

非金属及其化合物

氯，硫，氮，硅及其化合物。

系统教程

本课目标

  • 能准确描述氯、硫、氮、硅及其重要化合物的物理性质与化学性质
  • 会书写 Cl₂ 与水的可逆反应、NH₃ 的催化氧化、浓硫酸与铜反应等重要方程式
  • 理解浓硫酸的"三性"（吸水性、脱水性、强氧化性）及其区别
  • 掌握氨气、NO/NO₂ 的化学性质以及硅和硅酸盐材料的应用

知识讲解

非金属及其化合物的学习要抓住"氧化还原"和"特性反应"两条主线。

氯（Cl₂）：黄绿色有毒气体，能溶于水。Cl₂ + H₂O ⇌ HCl + HClO（可逆反应）。HClO 具有强氧化性、漂白性和杀菌性，但见光分解（2HClO 光= 2HCl + O₂↑）。

硫及其化合物：SO₂ 具有漂白性（可逆，加热恢复）和还原性（能被 O₂、Cl₂、HNO₃ 等氧化）。浓 H₂SO₄ 的"三性"：

  • 吸水性：吸收游离水，作干燥剂（不可干燥碱性气体 NH₃）。
  • 脱水性：将有机物中 H、O 按 2:1 脱去而炭化（如蔗糖变黑）。
  • 强氧化性：常温下使 Fe、Al 钝化；加热时与铜反应：Cu + 2H₂SO₄(浓) △= CuSO₄ + SO₂↑ + 2H₂O。

氮及其化合物：NH₃ 是中学唯一常见的碱性气体，极易溶于水（1:700），NO 遇 O₂ 立即变红棕色 NO₂（2NO + O₂ = 2NO₂），工业制硝酸：4NH₃ + 5O₂ 催化剂/△= 4NO + 6H₂O。

硅（Si）：半导体材料，SiO₂ 是光导纤维的主要成分，硅酸盐材料包括玻璃、水泥、陶瓷。

例题精讲

基础：氯水的成分与性质

题目：新制氯水具有哪些性质？光照一段时间后，氯水的成分和性质如何变化？

解答：新制氯水含 Cl₂、HClO、H⁺、Cl⁻、ClO⁻、H₂O，性质包括酸性（H⁺）、漂白性（HClO）、Cl⁻ 的性质等。光照后 HClO 分解（2HClO 光= 2HCl + O₂↑），HClO 减少，酸性增强，漂白性消失，最终变为稀盐酸。

氯水的性质取决于其成分：Cl₂ 有强氧化性，HClO 有漂白性，H⁺ 有酸性。

进阶：浓硫酸"三性"的判断

题目：下列现象分别体现浓硫酸的什么性质？①浓硫酸使胆矾晶体由蓝变白；②浓硫酸使蔗糖变黑膨胀；③浓硫酸与铜加热产生无色刺激性气体。

解答：①**吸水性**：吸收胆矾（CuSO₄·5H₂O）中的结晶水，变为无水 CuSO₄（白色）。②**脱水性**：将蔗糖（C₁₂H₂₂O₁₁）中 H、O 按 2:1 脱去，生成碳（变黑），同时产生气体膨胀。③**强氧化性**：Cu + 2H₂SO₄(浓) △= CuSO₄ + SO₂↑ + 2H₂O，生成 SO₂ 气体。

吸水→吸收现成的水；脱水→按 H₂O 比例脱去有机物中的 H、O；强氧化→发生氧化还原反应。

挑战：NO 与 NO₂ 的相互转化

题目：将盛满 NO₂ 的试管倒扣在水中，描述现象并计算剩余气体体积占原体积的比例（假设在试管中进行，气体体积在相同条件下测定）。

解答：红棕色气体变浅至无色，水面上升，最终剩余无色气体。反应：3NO₂ + H₂O = 2HNO₃ + NO。3 体积 NO₂ 生成 1 体积 NO，剩余气体体积占原体积的 **1/3**。

注意 NO 不与水反应且不溶于水（用排水法收集），NO₂ 能与水反应。

亲子互动

🧪 "浓硫酸脱水性与蔗糖黑面包实验"（约 8 分钟）

  1. 取少量蔗糖放入烧杯，滴加少量水润湿，再倒入适量浓硫酸，搅拌
  2. 观察：蔗糖逐渐变黑（炭化）、体积膨胀、产生疏松多孔的海绵状碳，并放出刺激性气体
  3. 解释：脱水性使蔗糖炭化（C₁₂H₂₂O₁₁ 浓硫酸= 12C + 11H₂O），C 与浓硫酸继续反应：C + 2H₂SO₄(浓) △= CO₂↑ + 2SO₂↑ + 2H₂O，产生大量气体使碳膨胀
  4. ⚠ 安全提示：该实验涉及浓硫酸，需佩戴护目镜和手套

💡 目的：通过观察"黑面包实验"，直观理解浓硫酸脱水性与强氧化性的协同作用。

课后练习

第 1 题：下列气体中，不能用浓硫酸干燥的是（ ）。A. O₂ B. NH₃ C. CO₂ D. HCl

答案：B

解析：NH₃ 是碱性气体，能与浓硫酸反应生成 (NH₄)₂SO₄，不能用浓硫酸干燥。其余均为中性或酸性气体，可以用浓硫酸干燥。

第 2 题：写出工业制硝酸三步反应的化学方程式。

答案：①4NH₃ + 5O₂ 催化剂/△= 4NO + 6H₂O；②2NO + O₂ = 2NO₂；③3NO₂ + H₂O = 2HNO₃ + NO

解析：第一步氨的催化氧化是工业制硝酸的基础，三步循环进行。

第 3 题：下列关于 SO₂ 的说法错误的是（ ）。A. SO₂ 能使品红溶液褪色，加热恢复 B. SO₂ 能使酸性高锰酸钾溶液褪色 C. SO₂ 与 H₂S 反应生成 S D. SO₂ 与 BaCl₂ 溶液反应生成白色沉淀

答案：D

解析：H₂SO₃ 酸性弱于 HCl，SO₂ 与 BaCl₂ 不反应（不能由弱酸制强酸）。A 体现漂白性，B 体现还原性，C 中 SO₂ + 2H₂S = 3S↓ + 2H₂O 体现氧化性。

第 4 题：玻璃、水泥、陶瓷都属于硅酸盐材料，其中制玻璃的主要原料是什么？写出制玻璃的主要反应。

答案：纯碱（Na₂CO₃）、石灰石（CaCO₃）和石英砂（SiO₂）。主要反应：Na₂CO₃ + SiO₂ 高温= Na₂SiO₃ + CO₂↑；CaCO₃ + SiO₂ 高温= CaSiO₃ + CO₂↑

解析：玻璃是 Na₂SiO₃、CaSiO₃ 和 SiO₂ 熔化在一起得到的物质，属于混合物，没有固定熔点。
