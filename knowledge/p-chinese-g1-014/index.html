声母 j、q、x

语文

认读声母 j、q、x，分清它们和平舌音、翘舌音。

拼音grade-1cnm:cnc_p014ccs-2022:1.PY.01

📚 系统教程

🎯 本课目标

  • 能正确认读声母 j, q, x
  • 能区分 j (不送气) 和 q (送气) 的读音
  • 能分清 j, q, x 与平舌音/翘舌音的区别
  • 能正确拼读含 j, q, x 的音节

📖 知识讲解

认识 j, q, x

这三个字母的发音位置比较靠前，舌尖抵在下齿龈：

  1. j (基)：舌面抬起，不喷气。像‘鸡’的开头。
  2. q (期)：舌面抬起，用力喷气。像‘气球’的开头。
  3. x (希)：舌面靠近硬腭，气流摩擦而出。像‘小鱼’的开头。

注意：它们和 z, c, s（平舌音）或 zh, ch, sh（翘舌音）完全不同，舌头是不翘起来的。

✏️ 例题精讲

区分 j 和 q

题目：读出：j (基) 和 q (期)。

解答：j 不送气，q 送气。

💡 感觉 q 的读法像是在轻轻地‘喷气’。

认读 x

题目：读出：x (希)。

解答：x 是摩擦音，声音比较尖。

💡 嘴角向两边稍微拉开一点点，读 x 会更自然。

🧩 亲子互动

试着读一读：j-q-x。然后观察镜子，看看读这三个音时，嘴巴是不是像在微笑一样？

📝 课后练习

第 1 题：听读音选字母：‘鸡’(jī) 的声母是？

✅ 答案：j

解析：‘鸡’的读音开头是 j。

第 2 题：听读音选字母：‘气’(qì) 的声母是？

✅ 答案：q

解析：‘气’的读音开头是 q。

第 3 题：听读音选字母：‘西’(xī) 的声母是？

✅ 答案：x

解析：‘西’的读音开头是 x。
