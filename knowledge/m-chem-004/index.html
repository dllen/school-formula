🎯 本课目标

  • 理解质量守恒定律的内容及其微观解释（反应前后原子种类、数目、质量不变）
  • 掌握化学方程式的书写原则和步骤：写→配→注→等
  • 能正确配平简单的化学方程式（最小公倍数法、观察法）
  • 能说出化学方程式在质的方面和量的方面的意义

📖 知识讲解

化学方程式是用化学式表示化学反应的式子。它简洁地告诉了我们"谁"和"谁"在什么条件下反应生成了"谁"，以及各物质之间的质量关系。

质量守恒定律：参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和。 微观解释：化学反应前后，原子的种类、数目、质量都不变。所以反应前后物质的总质量必然相等。

化学方程式的书写步骤：

  1. 写：写出反应物和生成物的化学式，中间用短线连接
  2. 配：配平（使两边各原子个数相等）。方法：最小公倍数法、观察法、奇数配偶法。注意：只改系数，不改化学式
  3. 注：注明反应条件（点燃、加热△、催化剂等），生成物中的气体标"↑"、沉淀标"↓"
  4. 等：把短线改成等号

化学方程式的意义（以 2H₂ + O₂ 点燃→ 2H₂O 为例）：

  • 质的方面：氢气和氧气在点燃条件下生成水
  • 量的方面：每4份质量的氢气与32份质量的氧气完全反应生成36份质量的水（质量比为4:32:36 = 1:8:9）

根据化学方程式计算的步骤： 设未知数 → 写出并配平方程式 → 标出相关物质的相对分子质量和已知量、未知量 → 列比例式 → 求解 → 简明作答。 注意：代入计算的质量必须是纯净物的质量，含杂质要先换算。

✏️ 例题精讲

基础：配平化学方程式

题目：配平：__Fe + __O₂ 点燃→ __Fe₃O₄

解答：用最小公倍数法。氧原子：左边2个，右边4个，最小公倍数为4，所以O₂前配2，Fe₃O₄前配1。此时右边有3个Fe，所以左边Fe前配3。答案：3Fe + 2O₂ 点燃→ Fe₃O₄

💡 配平只看原子个数是否相等，不要改右下角的数字（如把Fe₃O₄改成FeO）。

进阶：解释质量守恒

题目：镁条在空气中燃烧后，生成物的质量比原来镁条的质量增加了。这一反应遵守质量守恒定律吗？为什么？

解答：遵守。根据质量守恒定律，参加反应的镁和氧气的质量总和等于生成的氧化镁的质量。增加的质量就是参加反应的氧气的质量。所有化学反应都遵守质量守恒定律。

💡 有气体参加或生成的反应，验证质量守恒时必须在密闭容器中进行。

挑战：根据方程式计算

题目：工业上电解氧化铝制取金属铝。反应方程式为：2Al₂O₃ 通电→ 4Al + 3O₂↑。电解10t氧化铝，最多能生产多少吨铝？

解答：设最多能生产铝的质量为x。2Al₂O₃的相对质量=2×(27×2+16×3)=204；4Al的相对质量=4×27=108。204/10t = 108/x，x = 108×10t/204 ≈ 5.3t。答：最多能生产约5.3吨铝。

💡 根据方程式计算的依据是质量守恒定律，关键是正确写出方程式并计算相对分子质量。

🧩 亲子互动

⚖️ "质量守恒侦探"实验（约 10 分钟）

准备：小试管、气球、白磷（或火柴头）、天平、锥形瓶、细沙、玻璃管（如条件不足，可用铁钉+硫酸铜溶液的简单实验替代）。

简易版（铁钉+硫酸铜溶液）：

  1. 将铁钉和硫酸铜溶液分别称量，记录总质量
  2. 将铁钉放入硫酸铜溶液中，观察现象（铁钉表面析出红色物质，溶液颜色变浅）
  3. 反应结束后再次称量，比较反应前后质量是否相等
  4. 思考：铁+硫酸铜→铜+硫酸亚铁，原子重新组合但总质量不变

💡 目的：亲手验证质量守恒定律，理解"化学反应前后原子不会凭空产生或消失"。

📝 课后练习

第 1 题：配平下列化学方程式：__Al + __O₂ 点燃→ __Al₂O₃

✅ 答案：4Al + 3O₂ 点燃→ 2Al₂O₃

解析：氧原子最小公倍数为6，O₂配3，Al₂O₃配2，则Al配4。

第 2 题：化学方程式 S + O₂ 点燃→ SO₂ 表示哪些意义？（从"质"和"量"两方面回答）

✅ 答案：质的方面：硫和氧气在点燃条件下生成二氧化硫。量的方面：每32份质量的硫与32份质量的氧气完全反应生成64份质量的二氧化硫（微粒个数比为1:1:1）。

解析：化学方程式的意义分"质"和"量"两个层面回答。

第 3 题：6g碳在足量的氧气中充分燃烧，能生成多少克二氧化碳？（C + O₂ 点燃→ CO₂）

✅ 答案：设生成CO₂质量为x。12/6g = 44/x，x = 22g。答：能生成22克二氧化碳。

解析：碳的相对原子质量12，CO₂的相对分子质量44，列比例求解。

第 4 题：判断对错："镁带燃烧后固体质量增加，所以该反应不遵守质量守恒定律。"

✅ 答案：错误。

解析：增加的质量是参加反应的氧气的质量，所有化学反应都遵守质量守恒定律。

Q2: 镁条燃烧后质量增加，是否违反质量守恒定律？

参考答案不违反。增加的质量是参加反应的氧气的质量，所有反应都遵守质量守恒定律。

Q3: 电解36g水，理论上能生成多少克氢气？（2H₂O 通电→ 2H₂↑ + O₂↑）

参考答案设生成氢气x，36/36g = 4/x，x = 4g
