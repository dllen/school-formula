知识讲解

电学是初中物理的另一大重点。从家庭用电到各种电器，理解电学基本概念和公式是分析和解决电学问题的基础。

基础概念：

  • 电流 I：表示电流强弱，单位安培(A)。形成电流的条件：有电压 + 闭合电路。
  • 电压 U：使电流"流动"的原因，单位伏特(V)。电源提供电压。
  • 电阻 R：导体对电流的阻碍作用，单位欧姆(Ω)。电阻是导体本身的性质，与电压电流无关。

欧姆定律（核心公式）：I = U/R

  • 串联电路：I 处处相等；U = U₁ + U₂；R = R₁ + R₂。
  • 并联电路：U 处处相等；I = I₁ + I₂；1/R = 1/R₁ + 1/R₂。

电功与电功率：

  • 电功（消耗的电能）：W = UIt = Pt。单位焦耳(J)，生活中用"度"（kW·h），1 度 = 3.6×10⁶ J。
  • 电功率：P = W/t = UI = I²R = U²/R。单位瓦特(W)。
  • 技巧：P = I²R 适合串联（I 相同）比较功率；P = U²/R 适合并联（U 相同）比较功率。

焦耳定律：Q = I²Rt，电流通过导体产生的热量与电流的平方、电阻、通电时间成正比。

家庭电路与安全用电：

  • 电压 220 V；开关接在火线上；保险丝/空气开关在电流过大时切断电路。
  • 安全电压：不高于 36 V。

电与磁：

  • 奥斯特实验：电流周围存在磁场（电生磁）。
  • 电磁感应（法拉第）：磁生电 → 发电机的原理。
  • 电动机：通电导体在磁场中受力运动（电 → 机械能）。

例题精讲

基础：欧姆定律的简单计算

题目：一个电阻为 8 Ω 的导体，两端电压为 4 V，通过它的电流是多少？如果电压增大到 8 V，电流又是多少？电阻是多少？

解答：I₁ = U₁/R = 4/8 = 0.5 A；I₂ = U₂/R = 8/8 = 1 A；电阻不变，仍是 8 Ω（电阻是导体本身的性质）。

电阻是导体的性质，不随电压电流变化。不能说"电阻与电压成正比"——这是最常见的错误之一！

进阶：电功率的计算与"度"的换算

题目："220 V 60 W"的灯泡正常工作 5 小时，消耗多少度电？工作时的电流约多大？

解答：W = Pt = 0.06 kW × 5 h = 0.3 度（kW·h）；I = P/U = 60/220 ≈ 0.27 A。

计算电能时，如果求"度"，功率用 kW、时间用 h；如果求焦耳，功率用 W、时间用 s。

挑战：电动机与发电机的辨析

题目：电动机和发电机在原理、能量转化、电路结构上有什么区别？请用表格对比。

解答：电动机：原理是通电导体在磁场中受力运动；能量转化是电能 → 机械能；电路中有电源。发电机：原理是电磁感应（磁生电）；能量转化是机械能 → 电能；电路中无电源（是电源）。

判断技巧：有电源 → 电动机（用电）；无电源、对外供电 → 发电机（发电）。

课后练习

第 1 题：一个标有"6 V 3 W"的灯泡，正常工作时的电流是多少？电阻是多少？

答案：I = P/U = 3/6 = 0.5 A；R = U/I = 6/0.5 = 12 Ω（或 R = U²/P = 36/3 = 12 Ω）

解析：用 I=P/U 求电流，再用 R=U/I 或 R=U²/P 求电阻。

第 2 题：两个电阻 R₁=6 Ω、R₂=3 Ω 串联在 9 V 的电源上，求电路中的电流和每个电阻两端的电压。

答案：I = U/(R₁+R₂) = 9/(6+3) = 1 A；U₁ = IR₁ = 1×6 = 6 V；U₂ = IR₂ = 1×3 = 3 V

解析：串联电路电流相等，总电阻 = R₁+R₂，用欧姆定律求电流，再求各电阻电压。

第 3 题：下列说法正确的是：A. 电压是形成电流的原因 B. 电阻与电压成正比、与电流成反比 C. 保险丝应用电阻率小、熔点高的材料制成 D. 发电机的工作原理是通电导体在磁场中受力

答案：A

解析：A 正确；B 错误（电阻是导体性质）；C 错误（保险丝用电阻率大、熔点低的材料）；D 错误（这是电动机的原理，发电机是电磁感应）。

第 4 题：一个"110 V 50 W"的灯泡正常工作 2 小时，消耗多少焦耳的电能？

答案：W = Pt = 50 W × 7200 s = 360000 J = 3.6×10⁵ J

解析：求焦耳时，功率用 W、时间用 s。2 h = 7200 s。

参考答案I = U/R = 6/10 = 0.6A

参考答案W = Pt = 0.1kW × 10h = 1度（1kW·h）
