化学

离子反应

电解质，离子方程式，离子共存，离子检验。

系统教程

本课目标

  • 能准确判断电解质的类别（强电解质与弱电解质），理解电离方程式的书写规则
  • 会书写常见反应的离子方程式，掌握"拆删查"三步法
  • 理解离子共存的实质，能根据离子间反应判断溶液中离子能否大量共存
  • 掌握常见离子（Cl⁻、SO₄²⁻、CO₃²⁻、Fe³⁺ 等）的特征反应与检验方法

知识讲解

电解质（酸、碱、盐）在水溶液中或熔融状态下能导电，原因是发生了电离，产生了自由移动的离子。

离子方程式的书写——"拆删查"三步法：

  1. 拆：将强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、可溶性盐拆成离子形式；单质、氧化物、气体、沉淀、弱电解质（CH₃COOH、NH₃·H₂O、H₂O）保留化学式。
  2. 删：删去前后没有参加反应的旁观离子（spectator ions）。
  3. 查：检查原子守恒和电荷守恒。

离子共生的判断：离子之间若能发生以下反应，则不能大量共存：

  • 生成沉淀（如 Ba²⁺ + SO₄²⁻ = BaSO₄↓）
  • 生成气体（如 2H⁺ + CO₃²⁻ = CO₂↑ + H₂O）
  • 生成弱电解质（如 H⁺ + OH⁻ = H₂O，H⁺ + CH₃COO⁻ = CH₃COOH）
  • 发生氧化还原反应（如 Fe³⁺ 与 I⁻、NO₃⁻(H⁺) 与 Fe²⁺）

审题注意：题干中"酸性溶液"（含大量 H⁺）、"碱性溶液"（含大量 OH⁻）、"无色溶液"（排除 Cu²⁺蓝、Fe²⁺浅绿、Fe³⁺黄、MnO₄⁻紫红）等条件会缩小共存范围。

例题精讲

基础：书写离子方程式

题目：写出盐酸与氢氧化钠中和反应的离子方程式。

解答：化学方程式：HCl + NaOH = NaCl + H₂O。拆：H⁺ + Cl⁻ + Na⁺ + OH⁻ = Na⁺ + Cl⁻ + H₂O。删去旁观离子 Na⁺、Cl⁻：**H⁺ + OH⁻ = H₂O**。查：原子 2H+1O=2H+1O ✓，电荷 (+1)+(-1)=0 ✓。

强酸强碱中和反应的离子方程式都是 H⁺ + OH⁻ = H₂O，它代表一类反应。

进阶：离子共存判断

题目：在酸性溶液中，下列离子组能大量共存的是（ ）。A. Na⁺、CO₃²⁻、K⁺、Cl⁻ B. Ba²⁺、Cl⁻、H⁺、SO₄²⁻ C. K⁺、Na⁺、NO₃⁻、Cl⁻ D. Fe³⁺、OH⁻、Na⁺、NO₃⁻

解答：酸性溶液含大量 H⁺。A 中 H⁺ + CO₃²⁻ → CO₂↑ + H₂O，不共存。B 中 Ba²⁺ + SO₄²⁻ → BaSO₄↓，不共存。D 中 Fe³⁺ + 3OH⁻ → Fe(OH)₃↓，且 OH⁻ 与 H⁺ 也不共存。C 中离子间不反应，**选 C**。

先确定题干条件（酸性/碱性/无色），再逐一检查各组离子间是否反应。

挑战：离子的检验

题目：某溶液可能含 Cl⁻、SO₄²⁻、CO₃²⁻，请设计实验方案检验这三种离子。

解答：①取少量溶液，加足量稀硝酸，若产生气泡则含 CO₃²⁻（CO₃²⁻ + 2H⁺ = CO₂↑ + H₂O）。②再加过量 Ba(NO₃)₂ 溶液，若产生白色沉淀则含 SO₄²⁻（Ba²⁺ + SO₄²⁻ = BaSO₄↓）。③过滤后向滤液中加 AgNO₃ 溶液，若产生白色沉淀则含 Cl⁻（Ag⁺ + Cl⁻ = AgCl↓）。注意顺序：先检 CO₃²⁻，再检 SO₄²⁻，最后检 Cl⁻，避免干扰。

检验顺序很重要：CO₃²⁻ 用酸检，SO₄²⁻ 用 Ba²⁺ 检，Cl⁻ 用 Ag⁺ 检，且每一步要排除上一步的干扰。

亲子互动

🧪 "离子方程式诊断室"（约 8 分钟）

  1. 判断下列离子方程式是否正确，错误的请改正： (a) 铁与稀盐酸：Fe + 2H⁺ = Fe³⁺ + H₂↑ (b) 碳酸钙与盐酸：CO₃²⁻ + 2H⁺ = CO₂↑ + H₂O (c) 钠与水：2Na + 2H₂O = 2Na⁺ + 2OH⁻ + H₂↑
  2. 核对答案：(a) 错，应生成 Fe²⁺：Fe + 2H⁺ = Fe²⁺ + H₂↑；(b) 错，CaCO₃ 不拆：CaCO₃ + 2H⁺ = Ca²⁺ + CO₂↑ + H₂O；(c) 对。

💡 目的：通过找错练习，强化"什么物质能拆、什么不能拆"的核心规则。

课后练习

第 1 题：写出碳酸钙与稀盐酸反应的离子方程式。

答案：CaCO₃ + 2H⁺ = Ca²⁺ + CO₂↑ + H₂O

解析：CaCO₃ 是难溶物，不能拆成离子；HCl 拆成 H⁺ 和 Cl⁻；CaCl₂ 可溶拆成 Ca²⁺ 和 Cl⁻；删去旁观离子 Cl⁻。

第 2 题：在碱性溶液中，下列离子组能大量共存的是（ ）。A. Cu²⁺、Na⁺、Cl⁻、NO₃⁻ B. K⁺、Ba²⁺、Cl⁻、NO₃⁻ C. NH₄⁺、K⁺、Cl⁻、SO₄²⁻ D. Fe³⁺、K⁺、Cl⁻、NO₃⁻

答案：B

解析：碱性溶液含 OH⁻。A 中 Cu²⁺ + 2OH⁻ → Cu(OH)₂↓；C 中 NH₄⁺ + OH⁻ → NH₃·H₂O；D 中 Fe³⁺ + 3OH⁻ → Fe(OH)₃↓。B 中离子间不反应。

第 3 题：下列离子方程式书写正确的是（ ）。A. 铝与稀硫酸：Al + 3H⁺ = Al³⁺ + H₂↑ B. 氢氧化钡与稀硫酸：Ba²⁺ + SO₄²⁻ = BaSO₄↓ C. 氯气通入氢氧化钠溶液：Cl₂ + 2OH⁻ = Cl⁻ + ClO⁻ + H₂O D. 钠投入硫酸铜溶液：2Na + Cu²⁺ = 2Na⁺ + Cu

答案：C

解析：A 没配平，应为 2Al + 6H⁺ = 2Al³⁺ + 3H₂↑；B 漏了 H⁺ + OH⁻ = H₂O；D 中钠先与水反应，不会直接置换铜。C 正确。

第 4 题：检验某溶液中是否含有 SO₄²⁻，应加入什么试剂？如何排除 CO₃²⁻ 的干扰？

答案：先加足量稀盐酸酸化（排除 CO₃²⁻ 等干扰），再加 BaCl₂ 溶液，若产生白色沉淀则含 SO₃²⁻。

解析：加盐酸酸化可排除 CO₃²⁻（产生气泡）和 Ag⁺（产生 AgCl 沉淀）的干扰，再加 BaCl₂ 若产生不溶于酸的白色沉淀 BaSO₄，则证明含 SO₄²⁻。

实战练习

    参考答案H⁺+OH⁻=H₂O

  2. Q2下列能大量共存的是? H⁺、CO₃²⁻、Na⁺、Cl⁻
