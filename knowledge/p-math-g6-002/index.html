分数乘整数

数学

会计算分数乘整数，用分子乘整数做新的分子，分母不变。

📚 系统教程

🎯 本课目标

  • 掌握分数乘整数的计算方法
  • 理解分数乘整数的实际意义
  • 学会将计算结果约分为最简分数

📖 知识讲解

计算分数乘整数，我们可以把整数看作分母为 1 的分数。

计算法则：

  • 用分子乘整数，结果作为新分子；
  • 分母保持不变。

公式：$ rac{a}{b} imes c = rac{a imes c}{b}$

注意：计算结果如果不是最简分数，记得要约分。

✏️ 例题精讲

直接计算

题目：计算：$ rac{2}{9} imes 3$

解答：$ rac{2 imes 3}{9} = rac{6}{9} = rac{2}{3}$

💡 计算出 $ rac{6}{9}$ 后，发现分子分母都能被 3 整除，所以要约分。

进阶计算

题目：计算：$ rac{3}{8} imes 5$

解答：$ rac{3 imes 5}{8} = rac{15}{8}$ 或 $1 rac{7}{8}$

💡 结果可以是假分数，也可以转化为带分数。

🧩 亲子互动

尝试计算 $ rac{1}{5} imes 4$，想一想分母为什么不需要乘以 4？

📝 课后练习

第 1 题：计算 $ rac{1}{7} imes 3$。

✅ 答案：3/7

解析：分子 1 乘 3 等于 3，分母 7 不变。

第 2 题：计算 $ rac{2}{15} imes 5$ (结果请约分)。

✅ 答案：2/3

解析：$ rac{2 imes 5}{15} = rac{10}{15} = rac{2}{3}$。

第 3 题：计算 $ rac{5}{6} imes 4$ (结果请约分)。

✅ 答案：10/3 或 3 1/3

解析：$ rac{5 imes 4}{6} = rac{20}{6} = rac{10}{3}$。

参考答案6/7
