化学

氧化还原反应

氧化剂，还原剂，电子转移，配平。

系统教程

本课目标

  • 能准确判断氧化还原反应中的氧化剂、还原剂、氧化产物与还原产物
  • 会分析氧化还原反应中电子转移的方向与数目，能用双线桥法表示
  • 理解"升失氧，降得还"口诀的内在逻辑，建立化合价升降与电子转移的对应关系
  • 掌握化合价升降法（电子守恒法）配平氧化还原反应方程式

知识讲解

氧化还原反应是一类有电子转移（得失或共用电子对偏移）的反应。本质是电子转移，特征是化合价升降——抓住化合价变化就能识别和分析氧化还原反应。

基本概念（以反应 2Na + Cl₂ = 2NaCl 为例）：

  • 还原剂：失电子，化合价升高，被氧化，生成氧化产物。Na（0 → +1）是还原剂。
  • 氧化剂：得电子，化合价降低，被还原，生成还原产物。Cl₂（0 → -1）是氧化剂。

记忆口诀："升失氧，降得还"——化合价升高、失去电子、被氧化（还原剂）；化合价降低、得到电子、被还原（氧化剂）。

配平方法——化合价升降法：

  1. 标出化合价变化的元素
  2. 求化合价升降总数的最小公倍数，确定氧化剂、还原剂、氧化产物、还原产物的系数
  3. 观察法配平其他物质，检查原子守恒和电子守恒

核心守恒：化合价升总数 = 化合价降总数 = 转移电子总数。

例题精讲

基础：判断氧化剂与还原剂

题目：在反应 2Mg + O₂ = 2MgO 中，指出氧化剂和还原剂，并标出电子转移方向。

解答：Mg 化合价由 0 升至 +2，失 2e⁻，是**还原剂**；O₂ 中 O 化合价由 0 降至 -2，得 4e⁻，是**氧化剂**。电子由 Mg 转移给 O₂，共转移 4e⁻。

先标各元素的化合价，再看谁升谁降，套用口诀即可判断。

进阶：双线桥法表示电子转移

题目：用双线桥法表示反应 Zn + CuSO₄ = ZnSO₄ + Cu 的电子转移方向和数目。

解答：Zn（0 → +2）：失去 2e⁻，被氧化，Zn 是还原剂；Cu²⁺（+2 → 0）：得到 2e⁻，被还原，CuSO₄ 是氧化剂。双线桥：从 Zn 到 ZnSO₄ 中的 Zn 标"失 2e⁻"，从 CuSO₄ 中的 Cu 到 Cu 标"得 2e⁻"。

双线桥注意：两端指向同种元素（反应物和生成物中），标明"得/失"与电子数。

挑战：化合价升降法配平

题目：配平：Cu + HNO₃(稀) → Cu(NO₃)₂ + NO↑ + H₂O

解答：①标化合价变化：Cu(0→+2) 升 2；N(+5→+2) 降 3。②最小公倍数为 6：Cu 前配 3，NO 前配 2。③观察法配平：3Cu + 8HNO₃ = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。验证：电子 3×2 = 2×3 = 6 ✓。

先配平化合价变化的元素，再配平其他原子（H、O），最后验证电子守恒。

亲子互动

⚡ "电子侦探"配平竞赛（约 10 分钟）

  1. 写出反应：Fe₂O₃ + CO → Fe + CO₂（一氧化碳还原氧化铁）
  2. 标出化合价变化：Fe（+3 → 0），C（+2 → +4）
  3. 求最小公倍数，用化合价升降法配平
  4. 核对答案：Fe₂O₃ + 3CO = 2Fe + 3CO₂，电子转移 6e⁻

💡 目的：通过亲手配平，体会"电子守恒"是氧化还原反应配平的根本依据。

课后练习

第 1 题：在反应 2H₂S + SO₂ = 3S + 2H₂O 中，氧化剂、还原剂、氧化产物、还原产物分别是什么？

答案：氧化剂：SO₂；还原剂：H₂S；氧化产物：S；还原产物：S

解析：H₂S 中 S(-2→0) 被氧化，SO₂ 中 S(+4→0) 被还原，二者生成的都是 S。

第 2 题：下列反应中，水既不是氧化剂也不是还原剂的是（ ）。A. 2Na + 2H₂O = 2NaOH + H₂↑ B. Cl₂ + H₂O = HCl + HClO C. 2F₂ + 2H₂O = 4HF + O₂ D. 3NO₂ + H₂O = 2HNO₃ + NO

答案：B、D

解析：B 中 Cl₂ 自身氧化还原（Cl 0→-1 和 0→+1），H₂O 中元素化合价不变；D 中 NO₂ 自身氧化还原，水同样既不是氧化剂也不是还原剂。A 中 H₂O 是氧化剂（H⁺ 得电子），C 中 H₂O 是还原剂（O²⁻ 失电子）。

第 3 题：用化合价升降法配平：MnO₂ + HCl(浓) → MnCl₂ + Cl₂↑ + H₂O

答案：MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O

解析：Mn(+4→+2) 降 2，Cl(-1→0) 升 1×2 = 2，最小公倍数 2，Cl₂ 配 1，HCl 配 4。

第 4 题：在反应 MnO₂ + 4HCl(浓) = MnCl₂ + Cl₂↑ + 2H₂O 中，H Cl 表现的性质是（ ）。A. 只有酸性 B. 只有还原性 C. 酸性和还原性 D. 酸性和氧化性

答案：C

解析：4 mol HCl 中，2 mol Cl⁻ 进入 MnCl₂（表现酸性），2 mol Cl⁻ 被氧化为 Cl₂（表现还原性）。
