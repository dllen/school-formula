金属及其化合物

化学

钠，镁，铝，铁，铜及其化合物。

系统教程

本课目标

  • 能准确描述钠、铝、铁、铜及其重要化合物的物理性质与化学性质
  • 会书写钠与水、铝与NaOH溶液、Fe³⁺与KSCN等特征反应的化学方程式
  • 理解"结构决定性质"在金属及其化合物中的体现，建立性质与用途的联系
  • 掌握 Na₂CO₃ 与 NaHCO₃ 的鉴别方法以及 Fe²⁺/Fe³⁺ 的检验与转化

知识讲解

金属及其化合物的学习主线是"结构→性质→用途"。钠、铝、铁是三种典型的金属代表，分别体现了碱金属、两性金属、变价金属的特性。

钠（Na）：银白色、质软、密度比水小（0.97 g/cm³）。活泼性强，与水剧烈反应：2Na + 2H₂O = 2NaOH + H₂↑。保存于煤油中。

铝（Al）：典型的两性金属，既能与强酸反应，也能与强碱反应：2Al + 6HCl = 2AlCl₃ + 3H₂↑；2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑。Al₂O₃ 和 Al(OH)₃ 也是两性化合物。

铁（Fe）：变价金属，常见 +2 和 +3 价。Fe³⁺ 遇 KSCN 溶液变血红色（检验 Fe³⁺ 的特征反应）。Fe²⁺ 与 Fe³⁺ 可相互转化：2Fe³⁺ + Fe = 3Fe²⁺；2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻。

重要化合物对比：

  • Na₂CO₃（纯碱）与 NaHCO₃（小苏打）：NaHCO₃ 受热分解（2NaHCO₃ △= Na₂CO₃ + CO₂↑ + H₂O），Na₂CO₃ 不分解；与盐酸反应，NaHCO₃ 更剧烈。
  • Al₂O₃ 是两性氧化物，Fe₂O₃ 是碱性氧化物（红棕色，作红色颜料）。

例题精讲

基础：钠与水的反应

题目：将一小块钠投入滴有酚酞的水中，描述实验现象并解释。

解答：现象：①钠浮在水面（密度比水小）②熔成闪亮小球（反应放热、钠熔点低）③四处游动（生成 H₂ 推动）④发出嘶嘶声（气体产生）⑤溶液变红（生成 NaOH 呈碱性）。反应：2Na + 2H₂O = 2NaOH + H₂↑。

记现象用"浮熔游响红"五字诀，分别对应密度、熔点、气体、放热、碱性。

进阶：铝与碱反应的本质

题目：铝与 NaOH 溶液反应的氧化剂是什么？写出反应的氧化还原分析。

解答：总反应：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑。分两步：①2Al + 6H₂O = 2Al(OH)₃ + 3H₂↑（Al 失电子，H₂O 中 H⁺ 得电子，H₂O 是氧化剂）；②Al(OH)₃ + NaOH = NaAlO₂ + 2H₂O（非氧化还原）。合并后，**氧化剂是 H₂O**，还原剂是 Al。

不能认为 NaOH 是氧化剂，NaOH 在第 ② 步中只起酸碱中和作用。

挑战：Fe²⁺ 与 Fe³⁺ 的检验与转化

题目：某溶液可能含 Fe²⁺ 或 Fe³⁺，请设计实验方案检验并证明二者之间的转化。

解答：检验：①加 KSCN，变血红色→含 Fe³⁺；②若不变红，再加氯水后变红→含 Fe²⁺。转化：Fe²⁺ → Fe³⁺：加氯水（2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻）；Fe³⁺ → Fe²⁺：加铁粉（2Fe³⁺ + Fe = 3Fe²⁺）。

检验 Fe²⁺ 时，先加 KSCN 不变红（排除 Fe³⁺），再加氧化剂后变红，两步缺一不可。

亲子互动

🔬 "金属性质探究实验设计"（约 10 分钟）

  1. 现有三份无色溶液：Na₂CO₃、NaHCO₃、NaOH，只允许使用稀盐酸和酒精灯，请设计鉴别方案
  2. 方案：①分别加热，能产生使澄清石灰水变浑浊气体的是 NaHCO₃；②剩余两份中分别逐滴加盐酸，立即产生气体的是 Na₂CO₃（已无 NaHCO₃），无明显现象的是 NaOH
  3. 思考：能否用 CaCl₂ 溶液鉴别 Na₂CO₃ 和 NaHCO₃？（提示：Ca²⁺ + CO₃²⁻ = CaCO₃↓，Ca(HCO₃)₂ 可溶）

💡 目的：通过实验方案设计，理解不同化合物性质差异是物质鉴别的理论基础。

课后练习

第 1 题：下列关于金属钠的说法正确的是（ ）。A. 钠保存在水中 B. 钠着火可用水扑灭 C. 钠的密度比煤油大 D. 钠在空气中燃烧生成 Na₂O

答案：C

解析：钠保存在煤油中（密度比煤油大，沉在下方隔绝空气），A 错；钠着火用沙子扑灭，B 错；钠燃烧生成 Na₂O₂（淡黄色），D 错。

第 2 题：写出 Al₂O₃ 分别与稀盐酸和 NaOH 溶液反应的离子方程式。

答案：Al₂O₃ + 6H⁺ = 2Al³⁺ + 3H₂O；Al₂O₃ + 2OH⁻ = 2AlO₂⁻ + H₂O

解析：Al₂O₃ 是两性氧化物，与酸反应生成 Al³⁺ 和水，与碱反应生成 AlO₂⁻ 和水。

第 3 题：要除去 FeCl₂ 溶液中混有的少量 FeCl₃，应加入什么写出反应的离子方程式。

答案：加入过量铁粉，过滤。2Fe³⁺ + Fe = 3Fe²⁺

解析：利用 Fe³⁺ 被 Fe 还原为 Fe²⁺ 的性质，过量铁粉确保 Fe³⁺ 被完全除去，过滤除去剩余铁粉。

第 4 题：鉴别 Na₂CO₃ 和 NaHCO₃ 固体的方法有哪些？（写出两种）

答案：①加热法：能产生使澄清石灰水变浑浊气体的是 NaHCO₃；②加 CaCl₂ 溶液：产生白色沉淀的是 Na₂CO₃（Ca²⁺ + CO₃²⁻ = CaCO₃↓），无明显现象的是 NaHCO₃。

解析：NaHCO₃ 受热分解产生 CO₂，Na₂CO₃ 不分解；CaCO₃ 难溶而 Ca(HCO₃)₂ 可溶，故 CaCl₂ 只与 Na₂CO₃ 反应。
