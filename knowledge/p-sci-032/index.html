四季更替

科学

春夏秋冬的划分，季节变化的原因。

系统教程

本课目标

  • 能说出磁铁有南极（S）和北极（N）两个磁极，同名磁极相斥、异名磁极相吸
  • 知道磁铁能吸引铁、钴、镍等磁性材料，不吸引铜、铝、塑料等
  • 理解指南针是利用磁铁指南北的性质制成的，地球本身是一个大磁铁
  • 了解磁铁在生活中的应用：门吸、冰箱贴、扬声器、磁悬浮列车等

知识讲解

磁铁是我们生活中常见的东西，冰箱门上的贴扣、文具盒的开关、指南针……它们都用到了磁铁。磁铁有什么神奇的性质呢？

磁铁的磁极

磁铁上磁性最强的部分叫磁极。任何磁铁都有两个磁极：

  • 南极（S 极）：指向地理南方的磁极
  • 北极（N 极）：指向地理北方的磁极

⚠️ 磁极总是成对出现——把一块磁铁分成两半，每一半仍然有 N 极和 S 极！不存在只有单个磁极的磁铁。

磁极间的相互作用

  • 同名磁极相互排斥（N-N 排斥，S-S 排斥）
  • 异名磁极相互吸引（N-S 吸引）

简单记：同性相斥，异性相吸。

磁铁能吸引什么？

磁铁能吸引铁、钴、镍等磁性材料：

  • ✅ 能被吸引：铁钉、钢尺、一元硬币（含镍）、回形针
  • ❌ 不能被吸引：铜线、铝箔、塑料、木头、玻璃、纸张

⚠> 磁铁不能吸引所有金属！只能吸引铁、钴、镍。铜和铝不是磁性材料。

指南针——磁铁指方向的性质

  • 磁铁有指向性：自由悬挂的磁铁静止时，N 极指向北方，S 极指向南方
  • 指南针就是利用这个性质制成的：磁针的 N 极指向北方
  • 地球本身相当于一个大磁铁，有地磁场。地磁南极在地理北极附近，地磁北极在地理南极附近

磁铁的应用

  • 门吸：利用磁铁吸引铁的性质
  • 冰箱贴：磁铁吸引箱体
  • 扬声器/耳机：磁铁和线圈配合产生振动发声
  • 磁悬浮列车：利用同名磁极相斥使列车悬浮
  • 磁卡/磁带：利用磁性材料记录信息

例题精讲

基础：磁极间的相互作用

题目：有两根条形磁铁，一根的 N 极靠近另一根磁铁的 S 极，会怎样？如果一根的 N 极靠近另一根的 N 极，又会怎样？

解答：N 极靠近 S 极→异名磁极相互吸引；N 极靠近 N 极→同名磁极相互排斥。

记忆口诀：同性相斥（同名磁极互相推开），异性相吸（异名磁极互相拉近）。

进阶：判断物体是否被磁化

题目：小华有一根钢针和一根铁钉，但不知道哪个已经被磁化了。你能帮他设计一个方法来判断吗？

解答：方法一：用钢针/铁钉分别靠近已知磁铁的 N 极和S极，如果一次吸引一次排斥，说明已被磁化（只有磁极间才会排斥）；如果两次都吸引，说明没有被磁化。方法二：悬挂法——用细线悬挂物体，如果自动指向南北，说明已被磁化。

关键区别：磁铁既能吸引铁，也能排斥另一磁铁；普通铁钉只能被吸引，不会排斥。所以"排斥"是判断磁铁的关键现象。

挑战：指南针为什么会指南北？

题目：指南针的 N 极为什么指向地理北方？请用地磁场的知识解释。

解答：地球本身相当于一个大磁铁，有地磁场。地磁南极在地理北极附近。根据"异名磁极相吸"，指南针的 N 极（被地磁南极吸引）指向地理北极方向，S 极指向地理南极方向。

容易混淆：地理北极附近是地磁南极，地理南极附近是地磁北极。指南针 N 极指向地理北方，是因为被地磁南极吸引了。

亲子互动

🔬 小实验：探究磁铁的性质（约 10 分钟）

  1. 准备一块条形磁铁、一些回形针、铜片、铝箔、塑料尺、木块、铁钉
  2. 实验一：用磁铁分别靠近各种物体，记录哪些能被吸引、哪些不能
  3. 实验二：用磁铁的两端分别靠近回形针，感受磁力最强的地方（磁极）
  4. 实验三：用两块磁铁的 N-N、S-S、N-S 分别靠近，感受吸引和排斥
  5. 实验四：把磁铁用细线悬挂起来，观察静止时的指向
  6. 实验五：把磁铁放在一张纸下方，纸上撒铁屑，轻敲纸面——观察铁屑排列成的磁感线图案

💡 目的：通过动手实验，直观感受磁铁能吸引哪些材料、同名异名磁极的相互作用、磁铁的指向性，加深对磁铁性质的认识。

课后练习

第 1 题：判断对错：磁铁可以吸引所有金属。（ ）

答案：错误

解析：磁铁只能吸引铁、钴、镍等磁性材料，不能吸引铜、铝、金、银等金属。"吸引所有金属"是错误的。

第 2 题：选择题：把一块条形磁铁从中间切断，每一段有几个磁极？（A）0个 （B）1个 （C）2个 （D）无法确定

答案：C

解析：磁极总是成对出现。把一块磁铁分成两半，每一段仍然有 N 极和 S 极两个磁极。不存在单独的磁单极子。

第 3 题：填空题：同名磁极相互______，异名磁极相互______。指南针是利用磁铁______的性质制成的。地球本身相当于一个______。

答案：排斥；吸引；指南北（指向性）；大磁铁（有地磁场）

解析：同名相斥、异名相吸。指南针利用磁铁指方向的性质。地球有地磁场。

第 4 题：简答题：有两根外观相同的钢棒，一根有磁性，一根没有。请用两种方法区分它们。

答案：方法一：用一根钢棒靠近另一根的中部，能吸引说明靠近的这根有磁性（因为磁极在两端，中部磁性很弱，如果中部还能吸引说明另一根是被吸引的铁）；方法二：悬挂法，悬挂后指向南北的有磁性，不指向的没有磁性。

解析：关键是找到"排斥"现象或指向性，因为只有磁铁才能排斥另一磁铁或指向南北。
