📖 知识讲解

今天我们认识一个特殊的数字：0。

  • 什么是 0？ 当一个盘子里原本有 3 个苹果，被吃光了，现在一个也没有了，我们就用 0 来表示。
  • 怎么读？ 读作“零”。
  • 0 的大小： 0 表示没有，所以 0 比任何 1 到 5 的数都小。例如：$0 < 1$。

0 的含义

题目：小篮子里没有球，应该用哪个数字表示？

解答：0

💡 一个也没有，就是 0。

0 的比较

题目：比较 0 和 1，哪个数大？

解答：1 > 0

💡 1 比 0 多，所以 1 大。

📝 课后练习

第 1 题：有 3 个气球，全部飞走了，还剩几个？用数字表示。

✅ 答案：0

解析：全部飞走，一个也没有了，所以是 0。

第 2 题：比较 0 和 5，填符号： 0 $\square$ 5

✅ 答案：<

解析：0 比 5 小，所以填 $<$。

第 3 题：数字 0 读作什么？

✅ 答案：零

解析：数字 0 的读音是零。

第 4 题：在 0, 1, 2 这三个数中，最小的数是几？

✅ 答案：0

解析：0 表示没有，是这里面最小的。
