声母 d、t、n、l

语文

认读声母 d、t、n、l，分清不送气的 d 和送气的 t，也分清 n 和 l。

拼音grade-1cnm:cnc_p011ccs-2022:1.PY.01

📚 系统教程

🎯 本课目标

  • 能正确认读声母 d, t, n, l
  • 能分辨 d (不送气) 和 t (送气) 的读音区别
  • 能分清 n 和 l 的发音位置，避免混淆
  • 能用这些声母拼读简单的音节

📖 知识讲解

认识四个好朋友

  1. d 和 t：
    • d：舌尖顶住上牙龈，轻轻弹出，不喷气。像小鼓敲一下：d-d-d。
    • t：舌尖顶住上牙龈，用力弹出，喷出一口气。像小气球爆了：t-t-t。
  2. n 和 l：
    • n：舌尖顶住上牙龈，气流从鼻子里出来（鼻音）。
    • l：舌尖顶住上牙龈，气流从舌头两边出来（边音）。

✏️ 例题精讲

区分 d 和 t

题目：读出这两个音：d (得) 和 t (特)。

解答：d 读起来轻快，t 读起来有气流冲出。

💡 你可以把手放在嘴前，读 t 的时候能感觉到有风吹在手上，而读 d 没有。

区分 n 和 l

题目：读出这两个音：n (呢) 和 l (勒)。

解答：n 是鼻音，l 是边音。

💡 试着捏住鼻子读 l，声音不变；但捏住鼻子读 n，声音就变了！

🧩 亲子互动

请小朋友大声读出：d-t-n-l，并试着在空中用手指写出这四个字母。

📝 课后练习

第 1 题：听读音选字母：‘大’(dà) 的声母是？

✅ 答案：d

解析：‘大’的读音开头是 d。

第 2 题：听读音选字母：‘兔’(tù) 的声母是？

✅ 答案：t

解析：‘兔’的读音开头是 t，有送气感。

第 3 题：听读音选字母：‘龙’(lóng) 的声母是？

✅ 答案：l

解析：‘龙’的读音开头是 l。

第 4 题：听读音选字母：‘牛’(niú) 的声母是？

✅ 答案：n

解析：‘牛’的读音开头是 n。
