Is there 与 Are there

英语

把 There is 和 There are 改成疑问句，询问某处有没有。

语法grade-5cnm:cne_p130ces-2022:2.GR.03

系统教程

本课目标

  • 理解 Is there 和 Are there 的疑问句结构
  • 能够将 There is/are 陈述句转换为疑问句
  • 能根据主语的单复数正确选择疑问词
  • 掌握 any 在疑问句中的用法

知识讲解

要把“这里有...”变成“这里有...吗？”，只需要把 is/are 挪到句首即可：

  1. Is there + 单数名词?
    • 陈述句：There is a lake. $ ightarrow$ 疑问句：Is there a lake?
  2. Are there + 复数名词?
    • 陈述句：There are some fish. $ ightarrow$ 疑问句：Are there any fish?

小贴士：在 Are there 的疑问句中，通常会用到 any（一些），用来询问是否存在。

例题精讲

单数变疑问

题目：把 "There is a tree." 变成疑问句。

解答：Is there a tree?

将 Is 移到句首，句末加问号。

复数变疑问

题目：把 "There are some birds." 变成疑问句。

解答：Are there any birds?

将 Are 移到句首，some 通常在疑问句中变为 any。

亲子互动

我想知道你的书包里有没有一支笔，我会问：Is there a pen in your bag? 你能试着问我有没有书吗？

课后练习

第 1 题：____ there a mountain in the park? (填 Is 或 Are)

答案：Is

解析：a mountain 是单数，使用 Is there。

第 2 题：____ there any rivers here? (填 Is 或 Are)

答案：Are

解析：rivers 是复数，使用 Are there。

第 3 题：将 "There is a lake." 改为疑问句。

答案：Is there a lake?

解析：将 is 提前即可。

第 4 题：问“河里有鱼吗”，正确的句子是 ( ) A. Is there any fish in the river? B. Are there any fish in the river?

答案：B

解析：fish 在这里作为复数（鱼群），通常使用 Are there any fish。

实战练习

Q1: 问「河里有鱼吗」，应选哪一句？

参考答案Are there any fish in the river?
