📖 知识讲解

认识大面积单位

当我们测量森林、湖泊或城市的面积时，使用平方米（$ ext{m}^2$）数值太大，不方便。这时我们需要更大的单位：公顷 (hm²) 和 平方千米 (km²)。

  1. 公顷：边长 100 米的正方形面积就是 1 公顷。

    • 公式：$1 \text{公顷} = 100\text{米} \times 100\text{米} = 10000 \text{平方米}$

  2. 平方千米：边长 1000 米的正方形面积就是 1 平方千米。

    • 公式：$1 \text{平方千米} = 1000\text{米} \times 1000\text{米} = 1000000 \text{平方米}$

单位换算关系：

  • $1 \text{平方千米} = 100 \text{公顷}$
  • $1 \text{公顷} = 10000 \text{平方米}$

✏️ 例题精讲

简单换算

题目：5 公顷等于多少平方米？

解答：因为 1 公顷 = 10000 平方米，所以 $5 \times 10000 = 50000$ 平方米。

💡 公顷换算成平方米，在原数后面加上四个零。

单位转换

题目：3.5 平方千米等于多少公顷？

解答：因为 1 平方千米 = 100 公顷，所以 $3.5 \times 100 = 350$ 公顷。

💡 平方千米换算成公顷，小数点向右移动两位。

实际应用

题目：一个矩形林场长 2 公里，宽 500 米，面积是多少公顷？

解答：先统一单位：2 公里 = 2000 米。面积 = $2000 \times 500 = 1000000$ 平方米。因为 10000 平方米 = 1 公顷，所以 $1000000 \div 10000 = 100$ 公顷。

💡 计算面积前，一定要先统一长度单位。

📝 课后练习

第 1 题：8 公顷 = ( ) 平方米

✅ 答案：80000

解析：1 公顷 = 10000 平方米，8 * 10000 = 80000。

第 2 题：0.6 平方千米 = ( ) 公顷

✅ 答案：60

解析：1 平方千米 = 100 公顷，0.6 * 100 = 60。

第 3 题：一个正方形公园的边长是 200 米，它的面积是多少公顷？

✅ 答案：4

解析：面积 = 200 * 200 = 40000 平方米 = 4 公顷。

第 4 题：4.2 公顷 = ( ) 平方米

✅ 答案：42000

解析：4.2 * 10000 = 42000。
