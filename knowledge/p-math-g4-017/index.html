加法交换律和结合律

数学

知道两个数相加可以交换位置，三个数相加可以先把能凑整的两个加起来。

📚 系统教程

🎯 本课目标

  • 掌握加法交换律：a + b = b + a
  • 掌握加法结合律：(a + b) + c = a + (b + c)
  • 能够识别能凑成整十、整百的数
  • 能运用运算定律进行简便计算

📖 知识讲解

在加法运算中，有两个非常有用的规律：

  1. 加法交换律：两个数相加，交换加数的位置，和不变。 公式：a + b = b + a 例子：12 + 8 = 8 + 12

  2. 加法结合律：三个数相加，先把其中两个数相加，再把结果与第三个数相加，和不变。我们通常把能凑成整十、整百的数先结合在一起算。 公式：(a + b) + c = a + (b + c) 例子：28 + 15 + 72 $\rightarrow$ (28 + 72) + 15 = 100 + 15 = 115

✏️ 例题精讲

简单交换

题目：计算：45 + 19

解答：45 + 19 = 19 + 45 = 64

💡 简单的交换律在口算时可以根据习惯调整位置。

利用结合律凑整

题目：计算：127 + 38 + 73

解答：127 + (38 + 73) = 127 + 111 = 238 (不简便) $\rightarrow$ 错误！ 正确：(127 + 73) + 38 = 200 + 38 = 238

💡 寻找个位数相加能凑成10的数，比如 7+3=10。

综合应用

题目：计算：256 + 197 + 444

解答：(256 + 444) + 197 = 700 + 197 = 897

💡 先观察 6+4=10，5+4=9，2+4=6，256和444可以凑成700。

📝 课后练习

第 1 题：计算：145 + 267 + 55

✅ 答案：467

解析：(145 + 55) + 267 = 200 + 267 = 467

第 2 题：计算：312 + 489 + 188

✅ 答案：989

解析：312 + (489 + 188) = 312 + 677 = 989 (慢) $\rightarrow$ (312 + 188) + 489 = 500 + 489 = 989

第 3 题：填空：(45 + 12) + 55 = 45 + (___ + ___)

✅ 答案：12, 55

解析：根据加法结合律，括号的位置可以移动。
