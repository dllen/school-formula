📖 知识讲解

数与代数是初中数学的基石。我们先梳理几个核心概念：

有理数与实数：整数和分数统称有理数；有理数和无理数（如 √2、π）统称实数。每个实数都可以用数轴上的一个点来表示，实数与数轴上的点是一一对应的。

代数式：用运算符号把数和字母连接而成的式子。代数式分为有理式和无理式，其中有理式包括整式和分式。

整式与分式：单项式和多项式统称整式。分式形如 A/B，其中 A、B 都是整式，且 B 中含有字母。分式有意义的条件是 分母 B ≠ 0，这是解分式相关问题的"第一步"。

二次根式：形如 √a（a ≥ 0）。被开方数必须非负，这是二次根式有意义的前提。化简二次根式常用到积的算术平方根性质：√(ab) = √a · √b（a ≥ 0, b ≥ 0）。

✏️ 例题精讲

基础：判断代数式类型

题目：指出下列代数式各属于哪一类（整式、分式、二次根式）：3x²、1/(x+1)、√(a+2)。

解答：3x² 是单项式，属于整式；1/(x+1) 分母含字母，属于分式；√(a+2) 含有开方且被开方数含字母，属于二次根式（无理式）。

💡 判断的关键：分母是否含字母（分式），是否含有开方且被开方数含字母（二次根式），否则为整式。

进阶：分式有意义的条件

题目：当 x 取何值时，分式 (x+3)/(x-2) 有意义？

解答：分式有意义的条件是分母不为0。令 x - 2 ≠ 0，得 x ≠ 2。所以当 x ≠ 2 时，分式有意义。

💡 解"分式有意义"问题，令分母 ≠ 0，解不等式即可。

挑战：二次根式的化简

题目：化简 √12 - √3，并求近似值（√3 ≈ 1.732）。

解答：√12 = √(4×3) = 2√3。所以 √12 - √3 = 2√3 - √3 = √3 ≈ 1.732。

💡 化简二次根式时，先把被开方数分解成"完全平方数×另一个数"，再用 √(ab)=√a·√b 化简。

📝 课后练习

第 1 题：下列实数中，哪些是无理数：√4、π、0.5、√3、22/7？

✅ 答案：π 和 √3 是无理数（√4=2 是有理数，0.5 和 22/7 是有理数）

解析：无限不循环小数是无理数。√4=2 是整数，0.5 是分数，22/7 是分数，它们都是有理数。

第 2 题：当 x 为何值时，二次根式 √(3x-6) 有意义？

✅ 答案：x ≥ 2

解析：二次根式有意义要求被开方数 ≥ 0，即 3x - 6 ≥ 0，解得 x ≥ 2。

第 3 题：化简：√18 + √8。

✅ 答案：5√2

解析：√18 = 3√2，√8 = 2√2，所以 √18 + √8 = 3√2 + 2√2 = 5√2。

第 4 题：当 x 取何值时，分式 (x²-4)/(x+2) 的值为0？

✅ 答案：x = 2

解析：分式值为0的条件：分子为0且分母不为0。x²-4=0 得 x=±2；但 x=-2 时分母为0（舍去），所以 x=2。
