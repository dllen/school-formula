📖 知识讲解

遗传与进化是高中生物的逻辑主线，从孟德尔的宏观实验到 DNA 的分子机制，再到种群水平的进化规律。

孟德尔遗传定律：

  • 分离定律：杂合子（Aa）产生配子时，等位基因分离，配子比为 1:1。Aa 自交后代表现型比 3:1，基因型比 1:2:1（AA:Aa:aa）。
  • 自由组合定律：非同源染色体上的非等位基因自由组合。双杂合子（AaBb）自交后代表现型比 9:3:3:1，测交比 1:1:1:1。

减数分裂：染色体复制一次，细胞连续分裂两次，配子染色体数目减半。减数第一次分裂后期：同源染色体分离、非同源染色体自由组合；四分体时期可发生交叉互换（基因重组）。

伴性遗传：红绿色盲、血友病为伴X隐性遗传——男性患者多于女性，交叉遗传（父传女、母传子）。

DNA 是主要的遗传物质：

  • 结构：双螺旋，碱基互补配对（A=T，G≡C）。
  • 复制：半保留复制、边解旋边复制。复制 n 次产生 2ⁿ 个 DNA，含亲代链的 DNA 始终只有 2 个。
  • 基因表达：转录（DNA→mRNA，主要在细胞核）和翻译（mRNA→蛋白质，核糖体）。中心法则：DNA→RNA→蛋白质。

进化：种群是进化的基本单位；突变和基因重组提供原材料；自然选择决定进化方向；进化的实质是种群基因频率的改变；隔离（生殖隔离）导致物种形成。

✏️ 例题精讲

基础：分离定律的概率计算

题目：人类双眼皮（A）对单眼皮（a）为显性。一对夫妇均为双眼皮，生了一个单眼皮孩子，则他们再生一个双眼皮女儿的概率是多少？

解答：父母均为双眼皮却生单眼皮孩子（aa），说明父母基因型均为 Aa。再生一个双眼皮（A_）的概率 = 3/4；生女儿的概率 = 1/2。再生一个双眼皮女儿 = 3/4 × 1/2 = **3/8**。

💡 先根据子代隐性性状推断亲本基因型，再用"乘法定律"计算组合概率。

进阶：自由组合与 9:3:3:1 的变形

题目：基因型为 AaBb 的个体自交，后代中表现型与亲本（A_B_）不同的个体占多少比例？

解答：AaBb 自交后代表现型比 9:3:3:1。A_B_ 占 9/16，与亲本表现型不同的个体 = 1 - 9/16 = **7/16**（包括 A_bb 3/16、aaB_ 3/16、aabb 1/16）。

💡 9:3:3:1 可变形为 9:7、9:3:4、12:3:1、13:3 等，关键是理解每对基因分离比 3:1 的组合。

挑战：DNA 复制计算

题目：一个 DNA 分子含有 100 个碱基对，其中腺嘌呤（A）有 40 个。该 DNA 复制 3 次后，共需要游离的胞嘧啶（C）脱氧核苷酸多少个？

解答：A=T=40，C=G=(200-80)/2=60。复制 3 次产生 2³=8 个 DNA，新增 7 个 DNA。需要 C = 60×7 = **420 个**。公式：某种碱基数 ×(2ⁿ-1)。

💡 复制 n 次需要游离核苷酸 = 原有个数 ×(2ⁿ-1)，注意"复制 n 次"与"第 n 次复制"的区别（后者只需 ×2ⁿ⁻¹）。

🧩 亲子互动

🧬 "遗传方式判断推理"（约 10 分钟）

  1. 分析下图遗传系谱（文字描述）：患病母亲的儿子都患病，患病父亲的女儿都患病，男女患病比例相近
  2. 判断："无中生有"→隐性；"有中生无"→显性。若患病母亲儿子都患病→可能是伴X显性或常染色体显性
  3. 练习：一对夫妇，丈夫正常、妻子患红绿色盲（XbXb），他们的子女患病情况如何？
  4. 答案：女儿全为携带者（XBXb，正常），儿子全患病（XbY）

💡 目的：训练遗传系谱分析能力，掌握"无中生有是隐性、隐性遗传看女病"的判断口诀。

📝 课后练习

第 1 题：基因型为 AaBb（独立遗传）的个体测交，后代的基因型种类和比例分别是多少？

✅ 答案：4 种基因型，比例 1:1:1:1。AaBb 产生 AB、Ab、aB、ab 四种配子（1:1:1:1），与 aabb 测交后代为 AaBb:Aabb:aaBb:aabb = 1:1:1:1。

解析：测交是与隐性纯合子杂交，用来检测待测个体的配子类型及比例。

第 2 题：一个 DNA 分子中，一条链的碱基比例为 A:T:G:C = 1:2:3:4，则互补链中 A:T:G:C 的比例是多少？整个 DNA 分子中 A:T:G:C 的比例是多少？

✅ 答案：互补链：T:A:C:G = 1:2:3:4，即 A:T:G:C = 2:1:4:3。整个 DNA 分子：A:T:G:C = 3:3:7:7。

解析：互补链中 A 对应原链的 T，以此类推。整个 DNA 中 A=T、G=C，所以 A:T = (1+2):(2+1) = 3:3，G:C = (3+4):(4+3) = 7:7。

第 3 题：判断遗传方式：一对正常的夫妇生了一个患白化病的孩子，则白化病的遗传方式是什么？这对夫妇再生一个正常孩子的概率是多少？

✅ 答案：常染色体隐性遗传。夫妇均为 Aa，再生正常孩子（A_）的概率 = 3/4。

解析：父母正常却生患病孩子→"无中生有"→隐性；若为伴X隐性，父亲正常（XBY）不可能传递致病基因给女儿，但这里不分性别，故为常染色体隐性。

第 4 题：基因突变、基因重组、染色体变异的根本区别是什么？其中哪个能产生新的基因？

✅ 答案：基因突变是基因结构的改变（碱基对的增添、缺失、替换）；基因重组是原有基因的重新组合；染色体变异是染色体结构或数目的改变。只有基因突变能产生新的基因（等位基因），是生物变异的根本来源。

解析：基因突变产生新基因（根本来源），基因重组产生新基因型，染色体变异可在显微镜下观察到。
