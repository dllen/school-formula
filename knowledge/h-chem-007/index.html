知识讲解

化学反应原理是高中化学的理论核心，涵盖能量、速率、平衡和电化学四大板块。

反应热（ΔH）：ΔH = H(产物) - H(反应物)。放热反应 ΔH < 0（体系向环境释放能量，如燃烧反应）；吸热反应 ΔH > 0（体系从环境吸收能量，如大多数分解反应）。

化学反应速率：v = Δc/Δt（单位 mol·L⁻¹·s⁻¹ 等）。影响因素：

  • 浓度：增大反应物浓度 → 速率增大（活化分子数增多）
  • 温度：升高温度 → 速率增大（活化分子百分数增大）
  • 催化剂：降低活化能 → 速率增大（加快到达平衡，不影响平衡位置）
  • 压强（气体反应）：增大压强 → 速率增大（等效于增大浓度）

化学平衡：可逆反应达到 v正 = v逆 ≠ 0 的状态。勒夏特列原理：改变影响平衡的一个条件，平衡就向能够减弱这种改变的方向移动。

水溶液中的离子平衡：

  • 弱电解质电离：CH₃COOH ⇌ CH₃COO⁻ + H⁺（部分电离）
  • 盐类水解：谁弱谁水解，谁强显谁性（NaClO 是强碱弱盐，水解显碱性）
  • 原电池：负极氧化（失电子）、正极还原（得电子），电子从负极流向正极

例题精讲

基础：化学反应速率的计算

题目：在 2 L 密闭容器中，发生反应 2SO₂ + O₂ ⇌ 2SO₃。前 5 min 内 SO₂ 的物质的量从 4 mol 减少到 2 mol，求这段时间内用 SO₂ 表示的平均反应速率。

解答：Δc(SO₂) = (4-2)mol / 2L = 1 mol/L；v(SO₂) = Δc/Δt = 1 mol/L ÷ 5 min = **0.2 mol·L⁻¹·min⁻¹**。

注意：v = Δc/Δt 计算的是平均速率，用物质的量变化除以容器体积再除以时间。

进阶：勒夏特列原理的应用

题目：反应 N₂(g) + 3H₂(g) ⇌ 2NH₃(g) ΔH < 0 达到平衡后，分别改变以下条件，平衡如何移动？①增大 N₂ 浓度；②升高温度；③增大压强。

解答：①增大 N₂ 浓度 → 平衡**正向移动**（减弱 N₂ 浓度的增大）。②升高温度 → 平衡向**吸热方向（逆向）**移动（减弱温度的升高，该反应放热）。③增大压强 → 平衡向**气体体积减小方向（正向）**移动（正向 4 mol 气体→2 mol 气体）。

勒夏特列原理的核心是"减弱"而非"消除"——平衡移动只能部分抵消改变。

挑战：盐类水解与pH判断

题目：浓度均为 0.1 mol/L 的①NaCl ②NaClO ③NH₄Cl ④Na₂CO₃ 四种溶液，pH 由小到大的顺序是？

解答：①NaCl：强酸强盐，不水解，pH = 7。②NaClO：强碱弱酸盐，水解显碱性，pH > 7。③NH₄Cl：强酸弱碱盐，水解显酸性，pH < 7。④Na₂CO₃：强碱弱酸盐，CO₃²⁻ 水解程度大于 ClO⁻ 水解（H₂CO₃ 酸性弱于 HClO），碱性更强。pH 顺序：**③ < ① < ② < ④**。

水解程度取决于对应酸碱的强弱：酸越弱，其阴离子水解程度越大，溶液碱性越强。

亲子互动

⚖️ "化学平衡移动分析"（约 10 分钟）

  1. 写出合成氨反应：N₂ + 3H₂ ⇌ 2NH₃ ΔH = -92.4 kJ/mol
  2. 分析工业合成氨的条件选择：
    • 为何采用高压？（平衡向气体体积减小方向移动）
    • 为何采用适当高温 400~500℃？（兼顾速率与催化剂活性，虽平衡逆向移动但速率大幅提高）
    • 为何使用铁触媒？（加快反应速率，缩短到达平衡的时间）
  3. 讨论：达到平衡时，N₂ 的转化率为 15%，若增大 N₂ 浓度，其转化率如何变化？

💡 目的：理解工业条件选择是速率、平衡、催化剂活性三者权衡的结果。

课后练习

第 1 题：下列反应中，ΔH > 0 的是（ ）。A. 盐酸与氢氧化钠的中和反应 B. 甲烷的燃烧 C. Ba(OH)₂·8H₂O 与 NH₄Cl 的反应 D. 铝热反应

答案：C

解析：A、B、D 均为放热反应（ΔH < 0）。C 是吸热反应，反应后温度明显降低。

第 2 题：在密闭容器中发生反应：2NO₂(g) ⇌ N₂O₄(g)。当体系颜色不再改变时，说明反应达到平衡，对吗？为什么？

答案：对

解析：颜色深浅与 NO₂ 浓度有关。颜色不变 → NO₂ 浓度不变 → 各组分浓度不变 → 达到平衡状态。这是化学平衡"定"的特征。

第 3 题：写出铜-锌原电池（稀硫酸作电解质）的负极反应、正极反应和总反应。

答案：负极：Zn - 2e⁻ = Zn²⁺；正极：2H⁺ + 2e⁻ = H₂↑；总反应：Zn + H₂SO₄ = ZnSO₄ + H₂↑

解析：锌比铜活泼，作负极失电子；铜作正极，H⁺ 在正极得电子生成 H₂。

第 4 题：物质的量浓度相同的盐酸和醋酸分别与等量 NaOH 恰好完全反应，消耗 NaOH 的体积是否相同？为什么？

答案：相同

解析：中和反应的本质是 H⁺ + OH⁻ = H₂O。虽然醋酸中 H⁺ 浓度较小，但随着反应进行醋酸不断电离出 H⁺，最终提供的 H⁺ 总量等于其物质的量，与同浓度同体积的盐酸提供的 H⁺ 总量相同。
