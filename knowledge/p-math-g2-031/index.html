📖 知识讲解

🌟 加减法的小秘密

在数学王国里，加法和减法像是一对“好朋友”，它们之间有神奇的转换关系：

1. 加法家族： $\text{加数} + \text{加数} = \text{和}$

  • 如果你想找其中一个加数，可以用：$\text{和} - \text{已知加数} = \text{另一个加数}$

2. 减法家族： $\text{被减数} - \text{减数} = \text{差}$

  • 想找被减数（最大的数）？可以用：$\text{差} + \text{减数} = \text{被减数}$
  • 想找减数？可以用：$\text{被减数} - \text{差} = \text{减数}$

💡 记忆口诀：

  • 加法变减法，找加数；
  • 减法变加法，找被减数！

✏️ 例题精讲

简单求加数

题目：$\square + 200 = 500$，$\square$ 是多少？

解答：根据 $\text{和} - \text{加数} = \text{另一个加数}$，计算：$500 - 200 = 300$。所以 $\square = 300$。

💡 看到加法算式求加数，就用减法来算哦！

求被减数

题目：$\square - 150 = 300$，$\square$ 是多少？

解答：根据 $\text{差} + \text{减数} = \text{被减数}$，计算：$300 + 150 = 450$。所以 $\square = 450$。

💡 被减数是减法里最大的那个数，所以要用加法把它找回来。

综合应用验算

题目：计算 $600 - 250 = 350$，请用加法验算。

解答：利用 $\text{差} + \text{减数} = \text{被减数}$，计算：$350 + 250 = 600$。结果与原被减数相同，所以计算正确。

💡 验算就是用反向的操作来检查答案对不对。

📝 课后练习

第 1 题：$\square + 320 = 800$，$\square$ 等于多少？

✅ 答案：480

解析：用和减去已知加数：$800 - 320 = 480$。

第 2 题：$\square - 450 = 200$，$\square$ 等于多少？

✅ 答案：650

解析：用差加上减数：$200 + 450 = 650$。

第 3 题：$700 - \square = 300$，$\square$ 等于多少？

✅ 答案：400

解析：用被减数减去差：$700 - 300 = 400$。

第 4 题：小明有 $\square$ 颗弹珠，给了小红 120 颗后，还剩 280 颗。小明原来有多少颗弹珠？

✅ 答案：400

解析：算式为 $\square - 120 = 280$，计算 $280 + 120 = 400$ 颗。

第 5 题：已知 $450 + 150 = 600$，请写出一个对应的减法算式。

✅ 答案：$600 - 450 = 150$ 或 $600 - 150 = 450$

解析：和减去一个加数等于另一个加数。
