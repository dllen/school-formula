Design: Integration

How prompt templates connect with existing AI features and knowledge points

与现有 AI 功能的关系

Prompt 模板作为现有 AI 功能的"增强模式"，底层复用同一个 AI 调用服务。

简单模式：用户输入少量信息 → 使用固定 prompt → AI 输出

模板模式：用户选择模板 → 填写结构化变量 → 组装高质量 prompt → AI 输出

与知识点的关联

关联知识点的模板

  • 知识讲解类：自动填充当前知识点名称和描述
  • 公式推导类：自动关联对应公式
  • 错题分析类：关联知识点的常见错误模式

通用模板

  • 学习计划：不需要绑定特定知识点
  • 亲子互动：跨学科场景
  • 拓展探究：开放性主题
